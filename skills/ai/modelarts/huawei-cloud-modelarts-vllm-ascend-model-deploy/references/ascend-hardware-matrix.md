# 昇腾芯片型号与资源规格速查

本文件用于在 ModelArts 部署前快速确认目标资源规格(芯片型号 + TP 大小,见 SKILL.md 步骤 3.0),并据此回到 vllm-ascend 适配文档核对启动参数。

> **免责**: 下表为速查参考,数值以华为昇腾官网规格与 vllm-ascend 官方适配文档为准;型号信息不确定时向用户询问,不要猜测。

## 一、芯片型号 → 产品形态 → 关键规格

| 芯片型号(代际) | 典型产品形态 | 单卡显存参考 | 定位 |
|----------------|--------------|--------------|------|
| 910B 系列(A2) | Atlas 800I A2 / 800T A2 / 900 A2 / 900 RCK A2 | 910B3: 64GB;910B4(推理版): 32GB | 训练/推理通用,大模型推理首选,适配文档示例最多 |
| 910C(A3) | Atlas 900 A3 等 | 以官方规格为准 | 新一代,注意适配文档覆盖与 FP8 等特性支持 |
| **950 系列(A5)** | **950DT / 950PR** | **950DT: 96GB;950PR: 128GB** | 新一代高显存,**须细分到具体型号** |
| 310P | Atlas 300I Duo / 300V 等 | 24GB 量级 | **推理卡**,只适合小模型(7B 以下) |

> **⚠️ 950 系列必须细分 950DT / 950PR(强制)**: 用户答"A5"或"950 系列"时,禁止合并为单一选项直接开始提取参数——**必须用 AskUserQuestion 进一步确认具体型号**。两者虽共用同一镜像 tag(如 Qwen3.8-27B 的 `qwen3.8-a5`),但存在实际差异,直接影响脚本参数:

| 差异维度 | 950DT | 950PR |
|----------|-------|-------|
| 单卡显存 | 96GB | 128GB |
| 权重版本适配 | 以模型文档为准(如 Qwen3.8-27B: BF16 / w8a8-mxfp8) | 以模型文档为准(如 Qwen3.8-27B: BF16 / w8a8 推荐 / w8a8-mxfp8) |
| 启动示例参数 | 以模型文档为准(如 Qwen3.8-27B: `--max-model-len 131072`、`--gpu-memory-utilization 0.85`) | 以模型文档为准(如 Qwen3.8-27B: `--max-model-len 256000`、`--gpu-memory-utilization 0.9`) |

> 实例: Qwen3.8-27B 适配文档中 950DT 与 950PR 各给出独立启动示例,`--max-model-len` 与 `--gpu-memory-utilization` 值不同——**按用户确认的具体型号从文档提取参数,不得互相套用**。

## 二、芯片型号对部署脚本的影响维度

同一模型在不同芯片型号下,以下内容可能不同(务必按适配文档核对):

| 维度 | 影响 |
|------|------|
| 显存容量 | 决定单卡能否容纳模型权重 + KV Cache;不足则需多卡 TP 或换小模型 |
| dtype 支持 | 如 bfloat16 是否支持、FP8/INT8 量化(W8A8 等)是否可用 |
| 并行参数 | `--tensor-parallel-size` 按卡数设置;MoE 模型可能需 `--enable-expert-parallel` |
| 环境变量 | `VLLM_USE_V1`、`PYTORCH_NPU_ALLOC_CONF`、`HCCL_BUFFSIZE` 等可能因芯片/版本不同 |
| CANN/驱动版本 | 必须与镜像内 vllm-ascend 版本配套(官方配套表整行匹配) |

## 三、不同芯片 × 模型规模的常见配置(经验值,以适配文档为准)

| 芯片 | 7B 以下 | 7B | 14B~32B | 72B+ |
|------|---------|-----|---------|------|
| 910B3(64GB) | 1 卡 | 1 卡 | 2~4 卡 | 8 卡或多机 |
| 910B4(32GB) | 1 卡 | 2 卡 | 4~8 卡 | 不推荐 |
| 910C(A3) | 以适配文档为准 | 以适配文档为准 | 以适配文档为准 | 以适配文档为准 |
| 950DT(96GB) | 1 卡 | 1 卡 | 1~2 卡(大显存可单卡) | 以适配文档为准 |
| 950PR(128GB) | 1 卡 | 1 卡 | 1 卡(大显存) | 以适配文档为准 |
| 310P(24GB) | 1 卡 | 不推荐 | 不推荐 | 不支持 |

## 四、确认流程(对应 SKILL.md 步骤 3.0)

1. 向用户确认 ModelArts 资源池的**芯片型号**(必要时用 `npu-smi info` 在节点上确认)
2. **若为 950 系列(A5),必须继续细分确认 950DT / 950PR**(强制,禁止合并为单一选项)——两者单卡显存不同、同一模型适配文档示例参数可能不同,直接影响脚本取值
3. **确认 TP 大小**(步骤 3.0): 合法 TP 候选 = 模型注意力头数约数 ∩ 资源池卡数档位 ∩ 模型文档启动脚本 TP 值——资源池卡数档位**按芯片型号直接推导,与 ShowInferServiceCluster 查询无关**: **非 A3 芯片(910B(A2)/310P/950 系列等)档位 1/2/4/8;A3 芯片(910C)档位 2/4/6/8/16**。`ShowInferServiceCluster` 只在步骤 4 方式 A(API 自动部署)构造请求体 `flavor` 字段时才查询,与本步档位推导无关
4. 记录为部署方案的一部分(如 `Ascend 950DT,TP=4`)
5. 回到 SKILL.md 步骤 3.1,在 vllm-ascend 适配文档中找**与该芯片型号/TP 匹配**的启动示例
6. 若文档未覆盖该芯片型号 → 告知用户需自行验证适配,不保证可用
