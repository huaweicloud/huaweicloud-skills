# API Reference

## Overview

This document provides detailed reference for all OptVerse API endpoints used by the Solver Assistant skill.

## 1. CreateChat (SSE Streaming)

### 1.1 Endpoint

```
POST https://optverse.{region}.myhuaweicloud.com/v1/{project_id}/chats
Content-Type: application/json
Accept: text/event-stream
```

### 1.2 Headers

| Header | Required | Description |
|--------|----------|-------------|
| X-Chat-Route-Id | Yes | Conversation routing ID (UUID, must persist across rounds) |
| X-Auth-Token | Yes* | IAM token (*not needed with AKSK V4 signing) |
| Authorization | Yes* | AKSK V4 signature (*not needed with token) |
| X-Sdk-Date | Yes* | Request timestamp (*auto-generated by signing) |
| x-sdk-content-sha256 | Yes* | Body hash (*auto-generated by signing) |

### 1.3 Request Body

```json
{
  "message": "Requirement analysis text or confirmation message",
  "agent_type": "optverse",
  "id": "<existing_chat_id>",
  "filenames": ["需求分析输入.md"]
}
```

| Field | Required | Type | Description |
|-------|----------|------|-------------|
| message | Yes | string | Chat message (1-16384 chars) |
| agent_type | Yes | string | `optverse`, `predict`, `vrp`, `demand` |
| id | No | string | Existing chat_id for multi-round (omit for first round) |
| filenames | No | array | File attachment list (0-5 files; Round 1: demand file, Round 2+: empty) |

### 1.4 Response (SSE Stream)

```
data: {"chat_id": "8adba10e-...", "id": "b1f3c7d2-...", "create_time": "2025-09-11T06:32:41Z", "type": "chat_call", "message": {"content": "Partial content...", "tool_calls": []}}

data: {"chat_id": "8adba10e-...", "id": "b1f3c7d2-...", "message": {"content": " more content...", "tool_calls": []}}
```

### 1.5 Response Fields

| Field | Type | Description |
|-------|------|-------------|
| chat_id | string | Conversation ID (persist for subsequent rounds) |
| id | string | Message/answer ID (unique per round) |
| create_time | string | ISO 8601 timestamp |
| type | string | Message type (e.g., `chat_call`) |
| message.content | string | AI-generated response content (accumulated across SSE chunks) |
| message.tool_calls | array | Tool call results (may be empty) |

### 1.6 Calling Method

This endpoint is NOT available as an hcloud operation (SSE streaming not supported). Use the Python script:

```bash
python scripts/create_chat.py --message="<text>" --agent_type=optverse --filenames=<file> [--chat_id=<id>]
```

## 2. UploadFile

### 2.1 hcloud Command

```bash
hcloud OptVerse UploadFile \
  --X-Chat-Route-Id=<route-id> \
  --agent_type=optverse \
  --file=<file-path> \
  [--chat_id=<chat_id>] \
  --cli-region=cn-east-3
```

### 2.2 Parameters

| Parameter | Required | Type | Description |
|-----------|----------|------|-------------|
| --X-Chat-Route-Id | Yes | string | Routing ID (header) |
| --agent_type | Yes | string | Agent type |
| --file | Yes | file | File to upload (< 100MB) |
| --chat_id | No | string | Existing chat_id (for data file uploads) |
| --project_id | No | string | Project ID (auto-detected) |

### 2.3 Response

```json
{
  "chat_id": "8adba10e-4431-44c7-9d51-4b4140e9165b"
}
```

## 3. DownloadFile

### 3.1 hcloud Command

```bash
hcloud OptVerse DownloadFile \
  --chat_id=<chat_id> \
  --filename=<filename> \
  --X-Need-Content=true \
  --cli-region=cn-east-3
```

### 3.2 Parameters

| Parameter | Required | Type | Description |
|-----------|----------|------|-------------|
| --chat_id | Yes | string | Conversation ID |
| --filename | Yes | string | Artifact filename |
| --X-Need-Content | No | boolean | Set `true` to get content in response (default: false) |

### 3.3 Response

```json
{
  "download_url": "https://...",
  "content": "File content string..."
}
```

## 4. ListArtifacts

### 4.1 hcloud Command

```bash
hcloud OptVerse ListArtifacts \
  --chat_id=<chat_id> \
  --cli-region=cn-east-3
```

### 4.2 Response

```json
{
  "artifacts": [
    {
      "filenames": ["requirement_analysis.md", "model_formulation.md"],
      "stage_name": "requirement_analyzer",
      "create_time": "2025-09-11T06:32:41Z"
    },
    {
      "filenames": ["model_code.py", "model_doc.md"],
      "stage_name": "modeling",
      "create_time": "2025-09-11T06:35:12Z"
    }
  ]
}
```

### 4.3 Stage Names

| Stage Name | Description |
|------------|-------------|
| requirement_analyzer | Requirement analysis output |
| modeling | Model code and documentation |
| data | Data validation results |
| solver | Solver results |
| report | Business analysis report |

## 5. PublishChat

### 5.1 hcloud Command

```bash
hcloud OptVerse PublishChat \
  --chat_id=<chat_id> \
  --name=<asset-name> \
  --type=optverse \
  [--description=<description>] \
  --cli-region=cn-east-3
```

### 5.2 Parameters

| Parameter | Required | Type | Description |
|-----------|----------|------|-------------|
| --chat_id | Yes | string | Conversation ID (all stages must be confirmed) |
| --name | Yes | string | Published asset name (1-128 chars) |
| --type | Yes | string | `optverse`, `predict`, `vrp`, `demand` |
| --description | No | string | Asset description (0-1024 chars) |

### 5.3 Response

```json
{
  "id": "e476996d-6028-480f-bdb3-b6d4245e4155"
}
```

### 5.4 Precondition

All conversation stages must be confirmed before publishing. The server validates that the last stage's artifacts have been confirmed.

## 6. CancelChat (Optional)

```bash
hcloud OptVerse CancelChat \
  --X-Chat-Route-Id=<route-id> \
  --chat_id=<chat_id> \
  --cli-region=cn-east-3
```

Use this to cancel an in-progress SSE stream if the user wants to abort.

## 7. GetChat (Optional)

```bash
hcloud OptVerse ShowChat \
  --chat_id=<chat_id> \
  --cli-region=cn-east-3
```

Returns conversation details including message history.
