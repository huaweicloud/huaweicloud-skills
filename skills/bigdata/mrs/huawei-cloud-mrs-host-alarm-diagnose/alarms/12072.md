## 2. Log Directory

### 2.1 Log Priority

> When analyzing process exceptions, it is recommended to view logs in the following priority order:
>
> | Priority | Log Type | Description |
> |--------|----------|------|
> | 1 | HA log | HA resource detection results |

| Log File | Path | Purpose | Priority |

## 4. Detailed Log Descriptions

### 4.1 HA Resource Log (floatip.log)

#### Log Path
```
/var/log/Bigdata/omm/oms/ha/scriptlog/floatip.log*
```

#### Error Keywords

| Keyword | Description | Severity |
|--------|------|----------|
| `ERROR` | Error message | P1 |
| `WARN` | Warning message | P2 |
| `Alarm` | Alarm message | P0 |
| `down` | Network interface down | P0 |
| `is not exist` | IP does not exist | P1 |
| `unreachable` | IP unreachable | P1 |
| `Check status` | Status check | P3 |

#### Keyword Priority and Root Cause

| Priority | Keyword Combination | Root Cause | Possible Impact |
|--------|------------|----------|----------|
| P0 | `xxx down` | Network interface down | Floating IP unavailable |
| P0 | `Alarm` | Alarm triggered | Resource exception |
| P1 | `inet is not exist` | Network interface has no IP address | Network configuration issue |
| P1 | `is not exist` | Floating IP does not exist | IP not bound |
| P1 | `unreachable` | Floating IP unreachable | Network disconnected |
| P2 | `Check status is stopped` | Resource stopped | Normal state |
| P2 | `Check status is run alNormal` | Resource running abnormally | Needs attention |

## 5. System Commands

### 5.1 Configuration File Check

```bash
# Configuration file check retains original shell command
cat ${CONTROLLER_HOME}/inst/conf/oms-config.ini | grep -E "(float_ip|interface|netmask|gateway)" | grep -v "^#"
```

### 5.2 Network Status Check

```bash
python3 lakewatch_api_client.py -a collect_alarm_node_res_data \
  -p 'cluster_id=<cluster_id>' \
  -p 'strategy_name=network-interface-info' \
  -p 'node_name=<node_name>'

python3 lakewatch_api_client.py -a collect_alarm_node_res_data \
  -p 'cluster_id=<cluster_id>' \
  -p 'strategy_name=network-connectivity-test' \
  -p 'env={"TARGET_IP":"<floating_ip>"}' \
  -p 'node_name=<node_name>'
```

### 5.3 HA Resource Status Check

```bash
# Query the current HA-managed floatip resource status
python3 lakewatch_api_client.py -a collect_alarm_node_res_data \
  -p 'cluster_id=<cluster_id>' \
  -p 'strategy_name=ha-resource-status' \
  -p 'node_name=<node_name>'
```
