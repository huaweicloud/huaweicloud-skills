# Inter-Node Network Connectivity Exception Log Information

## 1. Alarm Type

| Item | Content |
|------|------|
| Alarm Name | Inter-node network connectivity exception |
| Alarm ID | 12089 |
| Alarm Type | Network monitoring |

---

## 2. Log Directory

### 2.1 Log Path

| Log File | Path | Purpose |
|----------|------|------|
| System log | `/var/log/messages` | System-level network log |

---

## 3. Log Time Format

### 3.1 System Log Format

```
Dec 20 10:30:15 hostname kernel: [message]
```

| Field | Description | Example |
|------|------|------|
| Date and time | Month Day HH:MM:SS | `Dec 20 10:30:15` |
| Hostname | Host name | `hostname` |
| Module | Kernel module | `kernel` |
| Message | Log body | `message` |

---

## 4. Error Keywords

### 4.1 Network-Related Keywords

| Keyword | Description | Severity |
|--------|------|----------|
| `not reachable` | Target unreachable | P0 |
| `unreachable` | Unreachable | P0 |
| `network is not well` | Network disconnected | P0 |
| `ping failed` | Ping failure | P0 |
| `Link detected: no` | Network interface link detection failure | P0 |
| `TX error` | Transmission error | P1 |
| `RX error` | Reception error | P1 |
