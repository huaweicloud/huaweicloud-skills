## 2. Log Directory

### 2.1 Log Priority

> When analyzing the diskmgt disk monitoring service unavailability, it is recommended to view logs in the following priority order:
>
> | Priority | Log Type | Description |
> |----------|----------|-------------|
> | 1 | System log | System-level service log |
> | 2 | NodeAgent log | Service detection log |

### 2.2 Log Path

| Log File | Path | Purpose | Priority |
|----------|------|---------|----------|
| System log | `/var/log/messages` | System-level service log | 1 |
| NodeAgent log | `${BIGDATA_LOG_HOME}/nodeagent/scriptlog/` | Service detection log | 2 |

## 7. Common Root Causes and Repair Suggestions

| Root Cause | Characteristics | Repair Suggestion |
|------------|----------------|-------------------|
| diskmgt service core file does not exist | `stat /usr/local/diskmgt/inner/diskmgtd` returns `No such file or directory` | Contact technical support to reinstall the diskmgt service |
| diskmgt service not started | Process check shows no diskmgtd process, systemctl status is inactive | Execute `systemctl restart diskmgt` to start the service |
| diskmgt service start failure | systemctl status shows failed | Check system logs to investigate the start failure cause, contact technical support |
| diskmgt service abnormally exited | System log contains diskmgtd crash records | Restart the service: `systemctl restart diskmgt`; if it still fails, contact technical support |
| System disk abnormality causing service unavailability | Disk health check abnormal | Fix the disk issue first, then restart the diskmgt service |
