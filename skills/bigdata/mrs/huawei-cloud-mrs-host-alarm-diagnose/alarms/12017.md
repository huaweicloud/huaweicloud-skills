# Disk Capacity Insufficient Log Information Description

## I. Alarm Type

| Item | Content |
|------|------|
| Alarm Name | Disk capacity insufficient |
| Alarm ID | 12017 |
| Alarm Type | System resource monitoring |
| Alarm Severity | Critical (default threshold 95%), Major (default threshold 85%) |

---

## II. Log Directory

### 2.1 Log Priority

> When analyzing disk capacity insufficiency, it is recommended to view logs in the following priority order:
>
> | Priority | Log Type | Description |
> |--------|----------|------|
> | 1 | System logs | System-level disk-related log information |
> | 2 | OMS logs | OMS system runtime logs |
> | 3 | Audit logs | Operation audit logs |

### 2.2 Log Paths

| Log File | Path | Purpose | Priority |
|----------|------|------|--------|
| System logs | `/var/log/messages*` | System-level disk-related log information | 1 |
| OMS logs | `/var/log/Bigdata/omm/` | OMS system runtime logs | 2 |
| Audit logs | `/var/log/Bigdata/omm/audit/` | Operation audit logs | 3 |

---

## III. Log Time Format

### 3.1 System Log Format

```
Dec 20 10:30:15 hostname process_name[pid]: message
```

| Field | Description | Example |
|------|------|------|
| Date and time | Month Day Hour:Minute:Second | `Dec 20 10:30:15` |
| Hostname | Host name | `hostname` |
| Process info | Process name and PID | `process_name[pid]` |
| Message content | Log body | `message` |

---

## IV. Abnormal Error Keywords

### 4.1 Disk Space Related Keywords

| Keyword | Meaning | Severity |
|--------|------|----------|
| `No space left on device` | Disk space is full | 🔴 P0 |
| `Cannot allocate memory` | Insufficient memory | 🔴 P0 |
| `disk full` | Disk is full | 🔴 P0 |
| `write error` | Write error | 🟠 P1 |
| `Read-only file system` | File system is read-only | 🔴 P0 |

### 4.2 Disk IO Related Keywords

| Keyword | Meaning | Severity |
|--------|------|----------|
| `I/O error` | IO error | 🔴 P0 |
| `ext4-fs error` | File system error | 🔴 P0 |
| `xfs_force_shutdown` | XFS file system forced shutdown | 🔴 P0 |
| `remounting read-only` | File system remounted as read-only | 🔴 P0 |

---

## V. Search Command Examples

### 5.1 Disk Space Usage

```bash
python3 lakewatch_api_client.py -a collect_alarm_node_res_data \
  -p 'cluster_id=<cluster_id>' \
  -p 'strategy_name=disk-space' \
  -p 'node_name=<node_name>'
```

### 5.2 Disk-Related Errors in System Logs

```bash
python3 lakewatch_api_client.py -a collect_alarm_log_data \
  -p 'cluster_id=<cluster_id>' \
  -p 'alarm_time=<alarm_time>' \
  -p 'log_directory=/var/log/' \
  -p 'log_file_name=messages*' \
  -p 'keywords=["No space left on device","disk full","I/O error","Read-only file system"]' \
  -p 'log_type=local' \
  -p 'node_name=<node_name>'
```

### 5.3 Disk-Related Errors in OMS Logs

```bash
python3 lakewatch_api_client.py -a collect_alarm_log_data \
  -p 'cluster_id=<cluster_id>' \
  -p 'alarm_time=<alarm_time>' \
  -p 'log_directory=/var/log/Bigdata/omm' \
  -p 'log_file_name=*.log*' \
  -p 'keywords=["No space left on device","disk full","write error"]' \
  -p 'log_type=local' \
  -p 'node_name=<node_name>'
```
