# Disk Inode Usage Exceeds Threshold (12051) Log Information

## I. Alarm Type

| Item | Content |
|------|---------|
| Alarm Name | Disk Inode Usage Exceeds Threshold |
| Alarm ID | 12051 |
| Alarm Type | Physical resource alarm |

---

## II. Log Directory

### 2.1 Log Priority

> When analyzing disk inode usage anomalies, it is recommended to view logs in the following priority order:
>
> | Priority | Log Type | Description |
> |----------|----------|-------------|
> | 1 | System log | System-level log information |
> | 2 | Temporary file directory | Temporary small file check |

### 2.2 Log Path

| Log File | Path | Purpose | Priority |
|----------|------|---------|----------|
| System log | `/var/log/messages` | System-level log information | 1 |
| Temporary file directory | `/tmp` | Temporary small file check | 2 |

## III. Log Time Format

### 3.1 System Log Format

```
Dec 20 10:30:15 hostname process_name[pid]: message
```

| Field | Description | Example |
|-------|-------------|---------|
| Date/Time | Month Day Hour:Minute:Second | `Dec 20 10:30:15` |
| Hostname | Host name | `hostname` |
| Process Info | Process name and PID | `process_name[pid]` |
| Message | Log body | `message` |

### 4.1 Inode-Related Keywords

| Keyword | Meaning | Severity |
|---------|---------|----------|

| `IFree` | Inode free count | P3 |

## VII. Common Root Causes and Repair Solutions

| Root Cause | Characteristics | Repair Solution |
|------------|----------------|-----------------|
| Too many small files written to disk | Inode usage exceeds threshold (default 80% important / 95% critical), high IUsed | Investigate partition small files: `for i in /*; do echo $i; find $i\|wc -l; done`, delete unnecessary small files |
| Temporary file accumulation | Large number of temporary files in `/tmp` directory | Clean up temporary files: `find /tmp -type f -mtime +7 -delete` |
| Log file fragmentation | Many small log files in log directory | Consolidate log files, clean up expired logs, adjust log rotation policy |
| Mail queue accumulation | Too many files in `/var/spool/postfix` directory | Clean up mail queue: `postsuper -d ALL` |
| File system inode limit too low | Partition total inode count insufficient, file count normal but usage rate high | Increase inode count when reformatting partition: `mkfs.ext4 -N <inode_count>` |
| Business design defect | Program continuously creates large numbers of small files | Optimize business logic, consolidate small files or use database instead |
