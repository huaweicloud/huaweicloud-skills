# Host File Handle Usage Rate High Log Information Description

## I. Alarm Type

| Item | Content |
|------|------|
| Alarm Name | Host File Handle Usage Rate High |
| Alarm ID | 12053 |
| Alarm Type | System Resource Monitoring |

---

## II. Log Directory

### 2.1 Log Priority

> When analyzing process anomalies, it is recommended to view logs in the following priority order:
>
> | Priority | Log Type | Description |
> |--------|----------|------|
> | 1 | System Log | System-level log information |
> | 2 | Process Log | Process file handle usage |

### 2.2 Log Path

| Log File | Path | Purpose | Priority |
|----------|------|------|--------|
| System Log | `/var/log/messages` | System-level log information | 1 |
| Temporary File Directory | `/tmp` | Temporary file check | 2 |

---

## III. Log Time Format

### 3.1 System Log Format

```
Dec 20 10:30:15 hostname process_name[pid]: message
```

| Field | Description | Example |
|------|------|------|
| Date and Time | Month Day Hour:Minute:Second | `Dec 20 10:30:15` |
| Hostname | Host name | `hostname` |
| Process Information | Process name and PID | `process_name[pid]` |
| Message Content | Log body | `message` |

---

## IV. Abnormal Error Keywords

### 4.1 File Handle Related Keywords

| Keyword | Meaning | Severity |
|--------|------|----------|
| `Too many open files` | File handle exhausted | 🔴 P0 |
| `file-nr` | File handle usage | 🟢 P3 |
| `Cannot allocate memory` | Insufficient memory | 🔴 P0 |

### 4.2 Process Related Keywords

| Keyword | Meaning | Severity |
|--------|------|----------|
| `CLOSE_WAIT` | Connection not closed | 🟠 P1 |
| `TIME_WAIT` | Waiting to close | 🟡 P2 |
| `ESTABLISHED` | Connection established | 🟢 P3 |
