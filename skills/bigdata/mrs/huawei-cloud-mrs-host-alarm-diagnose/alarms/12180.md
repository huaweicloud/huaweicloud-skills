# Disk IO Stuck (12180) Log Information

## 1. Alarm Type

| Item | Content |
|------|---------|
| Alarm Name | Disk IO Stuck |
| Alarm ID | 12180 |
| Alarm Type | Physical Resource Alarm |

---

## 2. Log Directory

### 2.1 Log Priority

> When analyzing disk IO stuck faults, it is recommended to view logs in the following priority order:
>
> | Priority | Log Type | Description |
> |----------|----------|-------------|
> | 1 | System log | System-level disk IO log |
> | 2 | Kernel log | Hardware error records |
> | 3 | Disk SMART info | Disk health status |

### 2.2 Log Path

| Log File | Path | Purpose | Priority |
|----------|------|---------|----------|
| System log | `/var/log/messages` | System-level disk IO log | 1 |
| Kernel log | `/var/log/kern.log` or `dmesg` | Hardware error records | 2 |
| Disk SMART | Obtained via `smartctl` | Disk health status | 3 |

## 3. Log Time Format

### 3.1 System Log Format

```
Dec 20 10:30:15 hostname kernel: [message]
```

| Field | Description | Example |
|------|-------------|---------|
| Date and time | Month Day HH:MM:SS | `Dec 20 10:30:15` |
| Hostname | Host name | `hostname` |
| Module | Kernel module | `kernel` |
| Message content | Log body | `message` |

## 4. Exception Error Keywords

### 4.1 Disk IO Stuck Keywords

| Keyword | Meaning | Severity |
|---------|---------|----------|
| `svctm` | Average service time; HDD>6s/SSD>3s indicates IO stuck | 🔴 P0 |
| `await` | Average I/O wait time; >30ms requires attention | 🟠 P1 |
| `%util` | Disk utilization; >99% with IOPS=0 indicates IO stuck | 🔴 P0 |
| `avgqu-sz` | I/O queue depth; >0 with IOPS=0 indicates IO stuck | 🔴 P0 |
| `iops` | I/O operations per second; =0 with %util>99% indicates IO stuck | 🔴 P0 |

### 4.2 Hardware Error Keywords

| Keyword | Meaning | Severity |
|---------|---------|----------|
| `I/O error` | I/O error | 🔴 P0 |
| `read-only` | Filesystem switched to read-only | 🔴 P0 |
| `device reset` | Device reset | 🟠 P1 |
| `timeout` | I/O timeout | 🟠 P1 |
| `link reset` | Link reset | 🟠 P1 |
| `ata` | ATA error | 🟠 P1 |
| `scsi` | SCSI error | 🟠 P1 |
| `nvme` | NVMe error | 🟠 P1 |

### 4.3 SMART Health Keywords

| Keyword | Meaning | Severity |
|---------|---------|----------|
| `Reallocated_Sector_Ct` | Reallocated sector count; >0 requires attention | 🟠 P1 |
| `Current_Pending_Sector` | Pending sector; >0 requires attention | 🟠 P1 |
| `Offline_Uncorrectable` | Offline uncorrectable error | 🔴 P0 |
| `UDMA_CRC_Error_Count` | Transfer error count | 🟠 P1 |
| `media_errors` | NVMe media error | 🔴 P0 |

## 7. Common Root Causes and Repair Suggestions

| Root Cause | Characteristics | Repair Suggestion |
|------------|----------------|-------------------|
| Disk aging | SMART has error items, svctm persistently high, dmesg has hardware errors | Replace the disk; before replacement, confirm whether it is on the active OMS or active node and perform active/standby switchover first |
| Disk hardware failure | SMART shows `Reallocated_Sector_Ct` or `Offline_Uncorrectable` | Replace the disk immediately to avoid data loss |
| RAID degraded or rebuilding | Sudden I/O spike, RAID status abnormal | Check RAID status, wait for rebuild to complete or replace the faulty disk |
| Filesystem read-only | System log shows `read-only`, disk switched to read-only | Check dmesg to confirm hardware error, replace the disk and remount |
| Disk queue buildup | avgqu-sz>0 and IOPS=0 and %util>99% | Confirmed as hardware IO stuck, replace the disk |
| NVMe media error | NVMe SMART shows `media_errors` | Replace the NVMe disk |

### Active/Standby Switchover Operation (Active OMS or Active Node Scenario)

When the IO-stuck disk is located on the active OMS node or the active node of an active/standby mode instance, perform the active/standby switchover first:
- Active OMS switchover: `sh ${OMS_RUN_PATH}/workspace/ha/module/hacom/tools/ha_client_tool --ip=127.0.0.1 --port=20013 --switchover --name=product`
- Instance active/standby switchover: On the Manager page, navigate to "Cluster > Services > Service Name", click "More" and select "Perform xxx Switchover"
