# Alarm Diagnosis Flow
## Execute the following command to obtain alarm diagnosis information and determine the alarm cause
```bash
python3 lakewatch_api_client.py -a query_alarm_skill \
  -p 'cluster_id=<cluster_id>' \
  -p 'alarm_sequence_id=<alarm_serial_no>'
```
Variable description:
<cluster_id>: Cluster ID, obtained from user input
<alarm_serial_no>: Alarm sequence number, obtained from user input
