## 7. Common Root Causes and Repair Suggestions

| Root Cause | Characteristics | Repair Suggestion |
|------------|----------------|-------------------|
| meta role status abnormal | meta process not running or status abnormal | On the Manager page, navigate to "Cluster > Services > meta" and restart the abnormal meta instance |
| meta service fails to call ECS API | meta log shows `Connection refused` or `timed out` | Check network connectivity from the meta node to the ECS service, investigate network issues |
| DNS resolution failure | DNS check shows resolution abnormality | Check `/etc/resolv.conf` configuration, confirm DNS server availability |
| AK/SK expired and cannot be refreshed | meta log shows `ak sk expired` | Check cluster agency binding status, rebind agency |
| Cluster has no agency bound | Cluster previously had an agency bound but it was unbound | Log in to the MRS management console, click "Agency Management" to rebind the agency |
| Insufficient agency permissions | meta log shows `403` or `401` | Check agency permission configuration, ensure the agency has ECS and OBS access permissions |
| ECS service unavailable | meta log shows `502` or `503` | Wait for ECS service recovery, or contact the cloud service administrator |
| OBS access failure in compute-storage separation scenario | AK/SK acquisition failure causes OBS access exception | After fixing the AK/SK acquisition issue, OBS access will automatically recover |

### Diagnosis Steps

1. Check meta role status: On the Manager page, navigate to "Cluster > Services > meta" > "Instances" to view status
2. If meta is abnormal, restart the meta instance
3. If meta is normal, log in to the alarm host to view `/var/log/Bigdata/meta/meta_servlet.log`
4. Based on the log error, determine:
   - Network error → Check network connectivity and DNS
   - Permission error → Check agency binding status
   - API unavailable → Wait for ECS service recovery
5. If the cluster has no agency bound, log in to the MRS management console to rebind
6. Wait 5 minutes for meta to automatically retry AK/SK acquisition, confirm alarm recovery
