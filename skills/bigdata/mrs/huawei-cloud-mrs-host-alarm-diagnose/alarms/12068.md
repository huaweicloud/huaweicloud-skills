## 2. Log Directory

### 2.1 Log Priority

> When analyzing process exceptions, it is recommended to view logs in the following priority order:
>
> | Priority | Log Type | Description |
> |----------|----------|-------------|
> | 1 | Process runtime log | Records business runtime logs, used to analyze business exceptions |
> | 2 | JVM error log | JVM fatal errors, crash information |
> | 3 | HA log | HA resource detection results |

### 2.2 Log Paths

| Log File | Path | Purpose | Priority |
|----------|------|---------|----------|
| Business log | `/var/log/Bigdata/controller/acs/acs*` | Account service business log | 2 |
| JVM error log | `/var/log/Bigdata/controller/acs-err*.log` | JVM fatal errors, crash information | 3 |
| HA resource log | `/var/log/Bigdata/omm/oms/ha/scriptlog/acs*` | HA detection results for ACS resource | 5 |

## 3. Log Time Format

### 3.1 Format A: Space-separated format (HA log, business log)

```
2024-12-20 10:30:15.123 CST  [Thread-1234] [Level] [Module] Message content
```

| Field | Description | Example |
|-------|-------------|---------|
| Date time | Year-Month-Day Hour:Minute:Second.Millisecond | `2024-12-20 10:30:15.123` |
| Timezone | CST timezone | `CST` |
| Thread ID | Thread identifier | `[Thread-1234]` |
| Log level | INFO/WARN/ERROR/FATAL | `[ERROR]` |
| Module name | Module identifier | `[ACS]` |
| Message content | Log body | `account service error` |

## 4. Detailed Description of Each Log Type

### 4.1 HA Resource Log (acs*)

#### Log Path
```
/var/log/Bigdata/omm/oms/ha/scriptlog/acs*
```

#### Exception Error Keywords

| Keyword | Meaning | Severity |
|---------|---------|----------|
| `ERROR` | Error message | P1 |
| `exception` | Exception caught | P1 |
| `Cannot find` | File not found | P1 |
| `Permission denied` | Permission denied | P1 |
| `Failed` | Operation failed | P1 |

#### Exception Keyword Priority and Root Causes

| Priority | Keyword Combination | Root Cause | Possible Impact |
|----------|---------------------|------------|-----------------|
| P1 | `ERROR` + `acs` | ACS service exception | Service unavailable |
| P1 | `Cannot find` + `XXX` | File missing | Service startup failure |
| P1 | `Permission denied` | Permission issue | Cannot access resource |
| P2 | `WARN` | Warning message | Potential issue |

#### Search Command Example

```bash
python3 lakewatch_api_client.py -a collect_alarm_log_data \
  -p 'cluster_id=<cluster_id>' \
  -p 'alarm_time=<alarm_time>' \
  -p 'log_directory=/var/log/Bigdata/omm/oms/ha/scriptlog' \
  -p 'log_file_name=acs*' \
  -p 'keywords=["ERROR","exception"]' \
  -p 'log_type=local' \
  -p 'node_name=<node_name>'
```

### 4.2 JVM Error Log (acs-err*.log)

#### Log Path
```
/var/log/Bigdata/controller/acs-err*.log
```

#### Exception Error Keywords

| Keyword | Meaning | Severity |
|---------|---------|----------|
| `OutOfMemoryError` | Out of memory | P0 |
| `java.lang.Exception` | Java exception | P1 |
| `SIGSEGV` | Segmentation fault | P0 |
| `SIGABRT` | Abnormal termination | P0 |

#### Exception Keyword Priority and Root Causes

| Priority | Keyword Combination | Root Cause | Possible Impact |
|----------|---------------------|------------|-----------------|
| P0 | `OutOfMemoryError` | JVM heap memory insufficient | Process crash |
| P0 | `SIGSEGV` | Memory access error | Process crash |
| P0 | `SIGABRT` | JVM fatal error | Process crash |
| P1 | `Exception` | Java application exception | Service exception |

#### Search Command Example

```bash
# View the latest ACS error log (JVM error log cannot be collected via the log API, original command retained)
latest_acs_err=$(ls -t /var/log/Bigdata/controller/acs-err*.log 2>/dev/null | head -1)
if [ -n "$latest_acs_err" ]; then
    cat "$latest_acs_err" | head -30
fi
```

## 8. Common Root Causes and Repair Suggestions

### 1. JVM Fatal Error

**Symptom:** Error records exist in the ACS error log (acs-err-*.log)

**Repair suggestions:**
- Analyze the error type and stack information in the error log
- Check whether system memory and CPU resources are sufficient
- Check whether there are bugs in third-party libraries or the JVM itself
- Submit an issue report to the development team

### 2. File Permission Issue (Most Common)

**Symptom:** `Cannot find XXX` or `Permission denied` appears in the HA log

**Repair suggestions:**
```bash
# Check related file/directory permissions
ls -la <file_path>

# Fix permissions (as needed)
chown omm:omm <file_path>
chmod 755 <directory>
chmod 644 <file>
```

### 3. Out of Memory (OOM)

**Symptom:** `OutOfMemoryError` appears in acs.log or error log

**Repair suggestions:**
- Check whether the JVM heap memory configuration is reasonable (default -Xmx2048m)
- Analyze the cause of memory leaks (check business code or third-party components)
- Consider increasing the heap memory size or optimizing business code
- Submit an issue report to the development team

### 4. File Handle Exhaustion

**Symptom:** `Too many open files` appears in the log

**Repair suggestions:**
```bash
# Check the current number of open files
lsof -p <pid> | wc -l

# Check system limits
cat /proc/sys/fs/file-max

# Temporarily increase the limit (requires root)
ulimit -n 65535
```

### 5. Port Conflict

**Symptom:** `Port already in use` or `BindException` appears in the log

**Repair suggestions:**
```bash
# Check port usage
netstat -tlnp | grep <port_number>
```

### 6. Insufficient Disk Space

**Symptom:** Log write failure or system prompt `No space left on device`

**Repair suggestions:**
```bash
# Check disk usage
df -h

# Clean up logs or temporary files
```
