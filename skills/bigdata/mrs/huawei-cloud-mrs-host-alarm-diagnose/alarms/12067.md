## 2. Log Directory

### 2.1 Log Path

| Log File | Path | Purpose |
|----------|------|------|
| HA resource log | `/var/log/Bigdata/omm/oms/ha/scriptlog/tomcat*` | HA detection result for Tomcat resource |
| catalina log | `/var/log/Bigdata/tomcat/catalina.out*` | Tomcat startup/runtime log |
| GC log | `/var/log/Bigdata/tomcat/tomcat_gc*` | Garbage collection log |
| Business log | `/var/log/Bigdata/tomcat/web*` | Business application log |
| Access log | `/var/log/Bigdata/tomcat/localhost_access_web_log*` | HTTP request access log |
| JVM error log | `/var/log/Bigdata/tomcat/hs_error*.log` | JVM fatal errors, crash information |

---

## 3. Log Time Format

### 3.1 Format A: Space-separated format

```
2024-12-20 10:30:15.123 CST  [Thread-1234] [Level] [Module] Message content
```

### 3.2 Format B: T-separated format (GC log)

```
2024-12-20T10:30:15.123+08:00: [GC pause (G1 Evacuation Pause) 4096M->1024M(4096M) 200.123ms]
```

### 3.3 Format C: Access log format

```
DD/Mon/YYYY:HH:MM:SS +0800
```

## 4. Detailed Description of Each Log Type

### 4.1 HA Resource Log (tomcat*)

#### Log Path
```
/var/log/Bigdata/omm/oms/ha/scriptlog/tomcat*
```

#### Exception Error Keywords

| Keyword | Meaning | Severity |
|--------|------|----------|
| `ERROR` | Error message | 🟠 P1 |
| `EXCEPTION` | Exception caught | 🟠 P1 |

#### Search Command Examples

```bash
python3 lakewatch_api_client.py -a collect_alarm_log_data \
  -p 'cluster_id=<cluster_id>' \
  -p 'alarm_time=<alarm_time>' \
  -p 'log_directory=/var/log/Bigdata/omm/oms/ha/scriptlog' \
  -p 'log_file_name=tomcat*' \
  -p 'keywords=["ERROR","EXCEPTION"]' \
  -p 'log_type=local' \
  -p 'node_name=<node_name>'
```

### 4.6 JVM Error Log

#### Log Path
```
/var/log/Bigdata/tomcat/hs_error*.log
```

#### Exception Error Keywords

| Keyword | Meaning | Severity |
|--------|------|----------|
| `OutOfMemoryError` | Out of memory | 🔴 P0 |
| `SIGSEGV` | Segmentation fault | 🔴 P0 |

#### Search Command Examples

```bash
# View the latest error log (JVM error logs cannot be collected via log API, original command retained)
latest_hs_error=$(ls -t /var/log/Bigdata/tomcat/hs_error*.log 2>/dev/null | head -1)
if [ -n "$latest_hs_error" ]; then
    cat "$latest_hs_error" | head -30
fi
```

## 6. Variable Substitution

| Variable | Description | Example |
|------|------|------|
| `<alarm_time>` | Alarm trigger time (Format A) | `2024-12-20 10` |
| `<alarm_time_before_1h>` | 1 hour before alarm time (Format A) | `2024-12-20 09` |
| `<alarm_time_m>` | Month/day format time | `Dec 20 10` |
| `<alarm_time_m_before_1h>` | 1 hour before month/day format time | `Dec 20 09` |
| `<alarm_time_t>` | T-separated format time | `2024-12-20T10` |
| `<alarm_time_t_before_1h>` | 1 hour before T-separated format time | `2024-12-20T09` |
| `<alarm_time_d>` | Log format time | `20/Dec/2024:10` |
| `<alarm_time_d_before_1h>` | 1 hour before log format time | `20/Dec/2024:09` |
