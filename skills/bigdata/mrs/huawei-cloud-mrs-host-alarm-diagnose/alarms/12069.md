## 2. Log Directory

### 2.1 Log Priority

> When analyzing process exceptions, it is recommended to view logs in the following priority order:
>
> | Priority | Log Type | Description |
> |----------|----------|-------------|
> | 1 | Process runtime log | Records business runtime logs, used to analyze business exceptions |
> | 2 | JVM error log | JVM fatal errors, crash information |
> | 3 | HA log | HA resource detection results |

### 2.2 Log Paths

| Log File | Path | Purpose | Priority |
|----------|------|---------|----------|
| Business log | `/var/log/Bigdata/controller/aos/aos.log*` | O&M operation business log | 2 |
| JVM error log | `/var/log/Bigdata/controller/aos/aos-err*.log` | JVM fatal errors, crash information | 3 |
| HA resource log | `/var/log/Bigdata/omm/oms/ha/scriptlog/aos*` | HA detection results for AOS resource | 5 |

## 3. Log Time Format

### 3.1 Format A: Space-separated format

```
2024-12-20 10:30:15.123 CST  [Thread-1234] [Level] [Module] Message content
```

| Field | Description | Example |
|-------|-------------|---------|
| Date time | Year-Month-Day Hour:Minute:Second.Millisecond | `2024-12-20 10:30:15.123` |
| Timezone | CST timezone | `CST` |
| Thread ID | Thread identifier | `[Thread-1234]` |
| Log level | INFO/WARN/ERROR/FATAL | `[ERROR]` |
| Module name | Module identifier | `[AOS]` |
| Message content | Log body | `operation service error` |

## 4. Detailed Description of Each Log Type

### 4.1 HA Resource Log (aos*)

#### Log Path
```
/var/log/Bigdata/omm/oms/ha/scriptlog/aos*
```

#### Exception Error Keywords

| Keyword | Meaning | Severity |
|---------|---------|----------|
| `ERROR` | Error message | P1 |
| `exception` | Exception caught | P1 |
| `Cannot find` | File not found | P1 |
| `Permission denied` | Permission denied | P1 |
| `Failed` | Operation failed | P1 |

#### Exception Keyword Priority and Root Causes

| Priority | Keyword Combination | Root Cause | Possible Impact |
|----------|---------------------|------------|-----------------|
| P1 | `ERROR` + `aos` | AOS service exception | Service unavailable |
| P1 | `Cannot find` + `XXX` | File missing | Service startup failure |
| P1 | `Permission denied` | Permission issue | Cannot access resource |

#### Search Command Example

```bash
python3 lakewatch_api_client.py -a collect_alarm_log_data \
  -p 'cluster_id=<cluster_id>' \
  -p 'alarm_time=<alarm_time>' \
  -p 'log_directory=/var/log/Bigdata/omm/oms/ha/scriptlog' \
  -p 'log_file_name=aos*' \
  -p 'keywords=["ERROR","exception"]' \
  -p 'log_type=local' \
  -p 'node_name=<node_name>'
```

---

### 4.2 JVM Error Log (aos-err*.log)

#### Log Path
```
/var/log/Bigdata/controller/aos/aos-err*.log
```

#### Exception Error Keywords

| Keyword | Meaning | Severity |
|---------|---------|----------|
| `OutOfMemoryError` | Out of memory | P0 |
| `java.lang.Exception` | Java exception | P1 |
| `SIGSEGV` | Segmentation fault | P0 |
| `SIGABRT` | Abnormal termination | P0 |

#### Exception Keyword Priority and Root Causes

| Priority | Keyword Combination | Root Cause | Possible Impact |
|----------|---------------------|------------|-----------------|
| P0 | `OutOfMemoryError` | JVM heap memory insufficient | Process crash |
| P0 | `SIGSEGV` | Memory access error | Process crash |
| P0 | `SIGABRT` | JVM fatal error | Process crash |
| P1 | `Exception` | Java application exception | Service exception |

#### Search Command Example

```bash
# View the latest AOS error log (JVM error log cannot be collected via the log API, original command retained)
latest_aos_err=$(ls -t /var/log/Bigdata/controller/aos/aos-err*.log 2>/dev/null | head -1)
if [ -n "$latest_aos_err" ]; then
    cat "$latest_aos_err" | head -200
fi
```

### 4.3 Business Log (aos.log)

#### Log Path
```
/var/log/Bigdata/controller/aos/aos.log*
```

#### Exception Error Keywords

| Keyword | Meaning | Severity |
|---------|---------|----------|
| `ERROR` | Error message | P1 |
| `WARN` | Warning message | P2 |
| `exception` | Exception caught | P1 |
| `OutOfMemoryError` | Out of memory | P0 |
| `Too many open files` | File handle exhausted | P1 |

#### Exception Keyword Priority and Root Causes

| Priority | Keyword Combination | Root Cause | Possible Impact |
|----------|---------------------|------------|-----------------|
| P0 | `OutOfMemoryError` | Out of memory | Process crash |
| P1 | `ERROR` + `aos` | Business error | Functional exception |
| P1 | `Too many open files` | File handle exhausted | Service exception |
| P2 | `WARN` | Warning message | Potential issue |

#### Search Command Example

```bash
python3 lakewatch_api_client.py -a collect_alarm_log_data \
  -p 'cluster_id=<cluster_id>' \
  -p 'alarm_time=<alarm_time>' \
  -p 'log_directory=/var/log/Bigdata/controller/aos' \
  -p 'log_file_name=aos.log*' \
  -p 'keywords=["exception","OutOfMemoryError"]' \
  -p 'log_type=local' \
  -p 'node_name=<node_name>'

python3 lakewatch_api_client.py -a collect_alarm_log_data \
  -p 'cluster_id=<cluster_id>' \
  -p 'alarm_time=<alarm_time>' \
  -p 'log_directory=/var/log/Bigdata/controller/aos' \
  -p 'log_file_name=aos.log*' \
  -p 'keywords=["error","warn"]' \
  -p 'log_type=local' \
  -p 'node_name=<node_name>'
```
