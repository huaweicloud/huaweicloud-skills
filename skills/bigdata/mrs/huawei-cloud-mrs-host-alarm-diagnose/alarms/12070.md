## 2. Log Directory

### 2.1 Log Priority

> When analyzing process exceptions, it is recommended to view logs in the following priority order:
>
> | Priority | Log Type | Description |
> |----------|----------|-------------|
> | 1 | Process runtime log | Records business runtime logs, used to analyze business exceptions |
> | 2 | JVM error log | JVM fatal errors, crash information |
> | 3 | GC log | Garbage collection logs, used to analyze memory issues |
> | 4 | HA log | HA resource detection results |

### 2.2 Log Paths

| Log File | Path | Purpose | Priority |
|----------|------|---------|----------|
| Business log | `/var/log/Bigdata/controller/controller.log*` | Controller business log | 2 |
| JVM error log | `/var/log/Bigdata/controller/hs_error*.log` | JVM fatal errors, crash information | 3 |
| GC log | `/var/log/Bigdata/controller/scriptlog/oms_gc.log*` | Garbage collection log | 4 |
| HA resource log | `/var/log/Bigdata/omm/oms/ha/scriptlog/controller.log*` | HA detection results for Controller resource | 5 |

## 3. Log Time Format

### 3.1 Format A: Space-separated format

```
2024-12-20 10:30:15.123 CST  [Thread-1234] [Level] [Module] Message content
```

| Field | Description | Example |
|-------|-------------|---------|
| Date time | Year-Month-Day Hour:Minute:Second.Millisecond | `2024-12-20 10:30:15.123` |
| Timezone | CST timezone | `CST` |
| Thread ID | Thread identifier | `[Thread-1234]` |
| Log level | INFO/WARN/ERROR/FATAL | `[ERROR]` |
| Module name | Module identifier | `[Controller]` |
| Message content | Log body | `controller service error` |

## 4. Detailed Description of Each Log Type

### 4.1 HA Resource Log (controller.log)

#### Log Path
```
/var/log/Bigdata/omm/oms/ha/scriptlog/controller.log*
```

#### Exception Error Keywords

| Keyword | Meaning | Severity |
|---------|---------|----------|
| `ERROR` | Error message | P1 |
| `exception` | Exception caught | P1 |
| `Connection refused` | Connection refused | P1 |
| `ConnectException` | Connection exception | P1 |
| `Permission denied` | Permission denied | P1 |

#### Exception Keyword Priority and Root Causes

| Priority | Keyword Combination | Root Cause | Possible Impact |
|----------|---------------------|------------|-----------------|
| P1 | `ERROR` + `controller` | Controller service exception | Service unavailable |
| P1 | `Connection refused` + `PMS` | PMS service connection failed | Functional exception |
| P1 | `Permission denied` | Permission issue | Cannot access resource |

#### Search Command Example

```bash
python3 lakewatch_api_client.py -a collect_alarm_log_data \
  -p 'cluster_id=<cluster_id>' \
  -p 'alarm_time=<alarm_time>' \
  -p 'log_directory=/var/log/Bigdata/omm/oms/ha/scriptlog' \
  -p 'log_file_name=controller.log*' \
  -p 'keywords=["ERROR"]' \
  -p 'log_type=local' \
  -p 'node_name=<node_name>'
```

### 4.2 JVM Error Log (hs_error*.log)

#### Log Path
```
/var/log/Bigdata/controller/hs_error*.log
```

#### Exception Error Keywords

| Keyword | Meaning | Severity |
|---------|---------|----------|
| `OutOfMemoryError` | Out of memory | P0 |
| `java.lang.Exception` | Java exception | P1 |
| `SIGSEGV` | Segmentation fault | P0 |
| `SIGABRT` | Abnormal termination | P0 |

#### Exception Keyword Priority and Root Causes

| Priority | Keyword Combination | Root Cause | Possible Impact |
|----------|---------------------|------------|-----------------|
| P0 | `OutOfMemoryError` | JVM heap memory insufficient | Process crash |
| P0 | `SIGSEGV` | Memory access error | Process crash |
| P1 | `Exception` | Java application exception | Service exception |

#### Search Command Example

```bash
# View JVM error log (JVM error log cannot be collected via the log API, original command retained)
ls -t /var/log/Bigdata/controller/hs_error*.log 2>/dev/null | head -1 | xargs -I {} cat {} 2>/dev/null | head -200
```

### 4.4 GC Log (oms_gc.log)

#### Log Path
```
/var/log/Bigdata/controller/scriptlog/oms_gc.log*
```

#### Log Time Format
```
2024-12-20T10:30:15.123+08:00: [GC pause (G1 Evacuation Pause) 4096M->1024M(4096M) 200.123ms]
```

#### Exception Error Keywords

| Keyword | Meaning | Severity |
|---------|---------|----------|
| `Full GC` | Full garbage collection | P1 |
| `GC pause` | GC pause | P2 |
| `OutOfMemoryError` | Out of memory | P0 |

#### Exception Keyword Priority and Root Causes

| Priority | Keyword Combination | Root Cause | Possible Impact |
|----------|---------------------|------------|-----------------|
| P0 | `OutOfMemoryError` | Out of memory | Process crash |
| P1 | `Full GC` | Frequent Full GC | Performance degradation |
| P2 | `GC pause` | GC pause | Slow response |

#### Search Command Example

```bash
python3 lakewatch_api_client.py -a collect_alarm_log_data \
  -p 'cluster_id=<cluster_id>' \
  -p 'alarm_time=<alarm_time>' \
  -p 'log_directory=/var/log/Bigdata/controller/scriptlog' \
  -p 'log_file_name=oms_gc.log*' \
  -p 'keywords=["Full GC","GC pause"]' \
  -p 'log_type=local' \
  -p 'node_name=<node_name>' \
  -p 'time_pattern=^\[([0-9]{4})-([0-9]{2})-([0-9]{2})T([0-9]{2}):([0-9]{2}):([0-9]{2})||ymdHMS'
```
