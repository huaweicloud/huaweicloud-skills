# Process Usage Over Threshold Log Information

## 1. Alarm Type

| Item | Content |
|------|------|
| Alarm Name | Process usage over threshold |
| Alarm ID | 12061 |
| Alarm Type | System resource monitoring |

---

## 2. Log Directory

### 2.1 Log Priority

> When analyzing process exceptions, it is recommended to view logs in the following priority order:
>
> | Priority | Log Type | Description |
> |--------|----------|------|
> | 1 | System log | System-level log information |
> | 2 | Process log | Process status and thread information |

### 2.2 Log Path

| Log File | Path | Purpose | Priority |
|----------|------|------|--------|
| System log | `/var/log/messages` | System-level log information | 1 |
| Java stack log | `/tmp/jstack_*.log` | Java thread stack information | 2 |

---

## 3. Log Time Format

### 3.1 System Log Format

```
Dec 20 10:30:15 hostname process_name[pid]: message
```

## 4. Exception Error Keywords

### 4.1 Process Status Keywords

| Keyword | Meaning | Severity |
|--------|------|----------|
| `Z` | Zombie process | 🟠 P1 |
| `D` | Uninterruptible sleep | 🔴 P0 |
| `W` | Sleep state | 🟢 P3 |
| `R` | Running | 🟢 P3 |
| `S` | Interruptible sleep | 🟢 P3 |

### 4.2 Thread-related Keywords

| Keyword | Meaning | Severity |
|--------|------|----------|
| `BLOCKED` | Blocked state | 🟠 P1 |
| `WAITING` | Waiting state | 🟠 P1 |
| `TIMED_WAITING` | Timed waiting | 🟡 P2 |
