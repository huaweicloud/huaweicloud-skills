## 2. Log Directory

### 2.1 Log Priority

> When analyzing process exceptions, it is recommended to view logs in the following priority order:
>
> | Priority | Log Type | Description |
> |--------|----------|------|
> | 1 | Error log | Process error log |
> | 2 | Access log | HTTP request access log |
> | 3 | HA log | HA resource detection results |

### 2.2 Log Path

| Log File | Path | Purpose | Priority |
|----------|------|------|--------|
| Error log | `/var/log/Bigdata/httpd/error_log` | Httpd error log | 3 |
| Access log | `/var/log/Bigdata/httpd/access_log*` | HTTP request access log | 4 |
| HA resource log | `/var/log/Bigdata/omm/oms/ha/scriptlog/httpd.log` | HA detection results for Httpd resource | 5 |

## 3. Log Time Format

### 3.1 Format A: Apache Standard Format

```
[Thu May 07 20:52:08.19087 2026] [core:notice] [pid 23695:tid 13...] AH00051: child pid 968293 exit signal Segmentation fault (11), possible coredump in /opt/...
```

| Field | Description | Example |
|------|------|------|
| Date and time | DD/Mon/YYYY HH:MM:SS.microseconds | `May 07 20:52:08.19087 2026` |
| Module | Log module | `core:notice` |
| Process info | pid and tid | `pid 23695:tid 13` |
| Error code | AH error code | `AH00051` |
| Message | Log body | `child pid exit signal` |

### 3.2 Access Log Format

```
8.5.XXX.XXX - - [07/May/2026:20:49:27 +0800] "GET /xxx HTTP/1.1" 200 1234 "-" "Mozilla/5.0"
```

| Field | Description | Example |
|------|------|------|
| Client IP | Visitor IP | `8.5.XXX.XXX` |
| Time | Access time | `07/May/2026:20:49:27 +0800` |
| Request | HTTP request | `GET /xxx HTTP/1.1` |
| Status code | Response status | `200` |
| Bytes | Bytes transferred | `1234` |

## 4. Detailed Log Descriptions

### 4.1 HA Resource Log (httpd.log)

#### Log Path
```
/var/log/Bigdata/omm/oms/ha/scriptlog/httpd.log
```

#### Error Keywords

| Keyword | Description | Severity |
|--------|------|----------|
| `ERROR` | Error message | P1 |
| `WARN` | Warning message | P2 |
| `exception` | Exception caught | P1 |
| `fault` | Error fault | P1 |

#### Keyword Priority and Root Cause

| Priority | Keyword Combination | Root Cause | Possible Impact |
|--------|------------|----------|----------|
| P1 | `ERROR` + `httpd` | Httpd service exception | Service unavailable |
| P2 | `WARN` | Warning message | Potential issue |

#### Search Command Example

```bash
python3 lakewatch_api_client.py -a collect_alarm_log_data \
  -p 'cluster_id=<cluster_id>' \
  -p 'alarm_time=<alarm_time>' \
  -p 'log_directory=/var/log/Bigdata/omm/oms/ha/scriptlog' \
  -p 'log_file_name=httpd.log' \
  -p 'keywords=["WARN","ERROR","exception"]' \
  -p 'log_type=local' \
  -p 'node_name=<node_name>'
```

### 4.2 Error Log (error_log)

#### Log Path
```
/var/log/Bigdata/httpd/error_log
```

#### Error Keywords

| Keyword | Description | Severity |
|--------|------|----------|
| `Segmentation fault` | Segmentation fault | P0 |
| `core:warn` | Warning message | P2 |
| `core:notice` | Notice message | P3 |
| `AH00XXX` | Apache error code | P1 |
| `Config variable.*is not defined` | Configuration variable not defined | P1 |
| `child pid.*exit signal` | Child process abnormal exit | P1 |
| `Permission denied` | Permission denied | P1 |
| `Address already in use` | Port already in use | P1 |
| `Cannot allocate memory` | Out of memory | P0 |

#### Keyword Priority and Root Cause

| Priority | Keyword Combination | Root Cause | Possible Impact |
|--------|------------|----------|----------|
| P0 | `Segmentation fault` | Process crash | Service interruption |
| P0 | `Cannot allocate memory` | Out of memory | Service interruption |
| P1 | `Config variable.*is not defined` | Configuration variable not defined | Configuration error |
| P1 | `child pid.*exit signal` | Child process abnormal exit | Service instability |
| P1 | `Address already in use` | Port conflict | Cannot start |
| P2 | `core:warn` | Warning message | Potential issue |

#### Search Command Example

```bash
python3 lakewatch_api_client.py -a collect_alarm_log_data \
  -p 'cluster_id=<cluster_id>' \
  -p 'alarm_time=<alarm_time>' \
  -p 'log_directory=/var/log/Bigdata/httpd' \
  -p 'log_file_name=error_log' \
  -p 'keywords=["error","warn","fault","Segmentation","coredump","exit signal"]' \
  -p 'log_type=local' \
  -p 'node_name=<node_name>'
```

### 4.3 Access Log (access_log)

#### Log Path
```
/var/log/Bigdata/httpd/access_log*
```

#### Log Time Format
```
DD/Mon/YYYY:HH:MM:SS +0800
```

#### Error Keywords

| Keyword | Description | Severity |
|--------|------|----------|
| `500` | Internal server error | P1 |
| `404` | Resource not found | P2 |
| `403` | Forbidden | P2 |
| `error` | Error request | P1 |

#### Keyword Priority and Root Cause

| Priority | Keyword Combination | Root Cause | Possible Impact |
|--------|------------|----------|----------|
| P1 | `500` | Internal server error | Service exception |
| P2 | `404` | Resource not found | Broken link |
| P2 | `403` | Forbidden | Permission issue |

#### Search Command Example

```bash
python3 lakewatch_api_client.py -a collect_alarm_log_data \
  -p 'cluster_id=<cluster_id>' \
  -p 'alarm_time=<alarm_time>' \
  -p 'log_directory=/var/log/Bigdata/httpd' \
  -p 'log_file_name=access_log*' \
  -p 'keywords=["error","500","404","403"]' \
  -p 'log_type=local' \
  -p 'node_name=<node_name>'

python3 lakewatch_api_client.py -a collect_alarm_log_data \
  -p 'cluster_id=<cluster_id>' \
  -p 'alarm_time=<alarm_time>' \
  -p 'log_directory=/var/log/Bigdata/httpd' \
  -p 'log_file_name=access_log*' \
  -p 'keywords=[]' \
  -p 'log_type=local' \
  -p 'node_name=<node_name>'
```
