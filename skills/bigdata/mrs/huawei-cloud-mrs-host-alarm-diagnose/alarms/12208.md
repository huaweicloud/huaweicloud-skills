## 2. Log Directory

### 2.1 Log Priority

> When analyzing NodeAgent Full GC anomalies, it is recommended to view logs in the following priority order:
>
> | Priority | Log Type | Description |
> |----------|----------|-------------|
> | 1 | NodeAgent log | Process runtime log |
> | 2 | GC log | JVM garbage collection log |
> | 3 | System log | System-level log information |

### 2.2 Log Paths

| Log File | Path | Purpose | Priority |
|----------|------|---------|----------|
| NodeAgent log | `${BIGDATA_LOG_HOME}/nodeagent/` | NodeAgent process runtime log | 1 |
| GC log | Path specified by `-Xloggc` in NodeAgent JVM parameters | JVM garbage collection log | 2 |
| System log | `/var/log/messages` | System-level log information | 3 |

## 3. Log Time Format

### 3.1 System Log Format

```
Dec 20 10:30:15 hostname process_name[pid]: message
```

### 3.2 GC Log Format

```
2026-06-11T16:00:32.123+0800: [GC (Allocation Failure) [PSYoungGen: 261120K->30720K(305664K)] 261120K->30720K(1004544K), 0.0123456 secs]
```

| Field | Description | Example |
|-------|-------------|---------|
| Timestamp | ISO format time | `2026-06-11T16:00:32.123+0800` |
| GC type | GC event type | `GC`, `Full GC` |
| Trigger reason | GC trigger reason | `Allocation Failure`, `System.gc()` |
| Memory region change | Memory changes per generation | `261120K->30720K(305664K)` |
| Duration | GC duration | `0.0123456 secs` |

## 7. Common Root Causes and Repair Solutions

### Full GC Trigger Cause Classification

| Cause | Characteristics | Verification Method | Repair Solution |
|-------|----------------|---------------------|-----------------|
| Old generation space insufficient (most common) | jstat shows high O (Old) usage | jstat -gcutil check O column | Increase heap memory (-Xmx), or optimize object lifecycle |
| Metaspace space insufficient | jstat shows high M (Metaspace) usage | jstat -gcutil check M column | Increase Metaspace: -XX:MaxMetaspaceSize=512m |
| Explicit System.gc() call | GC log shows `System.gc()` | Check GC log keywords | Add JVM parameter: -XX:+DisableExplicitGC |
| CMS concurrent mode failure | GC log shows `Concurrent Mode Failure` | Check GC log keywords | Increase old generation or lower CMSInitiatingOccupancyFraction=70 |
| Promotion failure | GC log shows `promotion failed` | Check GC log keywords | Increase old generation, adjust MaxTenuringThreshold |
| RMI system GC scheduled trigger | Full GC triggered at fixed hourly intervals | Check whether RMI is used | Add -XX:+DisableExplicitGC |
| Direct memory insufficient | Heap memory normal but Full GC frequent | Check DirectByteBuffer usage | Increase -XX:MaxDirectMemorySize |

### Common Memory Leak Scenarios

| Scenario | Characteristics | Investigation Clues |
|----------|----------------|---------------------|
| Static collection not cleaned | HashMap/ConcurrentHashMap continuously growing | static field referencing large objects |
| ThreadLocal not cleaned | Entry leak in thread pool scenarios | Large number of ThreadLocalMap$Entry |
| Unclosed connections | DB connection/IO stream leak | Many Connection/Socket objects |
| Unregistered listeners | Repeated Listener registration | Event source object accumulation |
| Cache without eviction policy | Self-implemented cache without size limit | Business objects continuously growing |
| Large objects directly entering old generation | Exceeds PretenureSizeThreshold | Many byte[]/array objects |

### Repair Solutions

| Root Cause | Repair Solution | Requires User Confirmation |
|------------|-----------------|---------------------------|
| Unreasonable heap memory configuration | Contact technical support to modify NodeAgent memory configuration, increase -Xmx | Yes |
| Memory leak | Contact technical support to analyze heap dump and locate leak point, fix code | Yes |
| System.gc() call | Add JVM parameter -XX:+DisableExplicitGC | Yes |
| Improper CMS configuration | Adjust -XX:CMSInitiatingOccupancyFraction=70 -XX:+UseCMSInitiatingOccupancyOnly | Yes |
| Metaspace insufficient | Increase -XX:MaxMetaspaceSize=512m | Yes |
| Process restart needed | Restart NodeAgent process | Yes |
