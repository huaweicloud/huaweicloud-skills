## 2. Log Directory

### 2.1 Log Priority

> When analyzing process exceptions, it is recommended to view logs in the following priority order:
>
> | Priority | Log Type | Description |
> |--------|----------|------|
> | 1 | Startup/shutdown script log | Records process startup/stop operations, analyze first |
> | 2 | Process runtime log | Records business runtime logs, analyze business exceptions |
> | 3 | HA log | HA resource detection results |

### 2.2 Log Path

| Log File | Path | Purpose | Priority |
|----------|------|------|--------|
| Script log | `/var/log/Bigdata/omm/oms/fms/scriptlog/fms_script.log*` | FMS startup/shutdown script log | 1 |
| Runtime log | `/var/log/Bigdata/omm/oms/fms/fms.log*` | FMS business runtime log | 2 |
| HA log | `/var/log/Bigdata/omm/oms/fms/scriptlog/fms_ha.log*` | HA detection results for FMS resource | 3 |

## 3. Log Time Format

### 3.1 Format A: Space-Separated Format

```
2024-12-20 10:30:15.123 CST  [Thread-1234] [Level] [Module] Message content
```

| Field | Description | Example |
|------|------|------|
| Date and time | YYYY-MM-DD HH:MM:SS.milliseconds | `2024-12-20 10:30:15.123` |
| Timezone | CST timezone | `CST` |
| Thread ID | Thread identifier | `[Thread-1234]` |
| Log level | INFO/WARN/ERROR/FATAL | `[ERROR]` |
| Module name | Module identifier | `[FMS]` |
| Message | Log body | `file management service error` |

## 4. Detailed Log Descriptions

### 4.1 Script Log (fms_script.log)

#### Log Path
```
/var/log/Bigdata/omm/oms/fms/scriptlog/fms_script.log*
```

#### Error Keywords

| Keyword | Description | Severity |
|--------|------|----------|
| `ERROR` | Error message | P1 |
| `OutOfMemoryError` | Out of memory | P0 |
| `exception` | Exception caught | P1 |
| `Failed` | Operation failed | P1 |

#### Keyword Priority and Root Cause

| Priority | Keyword Combination | Root Cause | Possible Impact |
|--------|------------|----------|----------|
| P0 | `OutOfMemoryError` | JVM heap memory insufficient | Process crash |
| P1 | `ERROR` + `fms` | FMS service exception | Service unavailable |
| P1 | `exception` | Business exception | Functional exception |

#### Search Command Example

```bash
python3 lakewatch_api_client.py -a collect_alarm_log_data \
  -p 'cluster_id=<cluster_id>' \
  -p 'alarm_time=<alarm_time>' \
  -p 'log_directory=/var/log/Bigdata/omm/oms/fms/scriptlog' \
  -p 'log_file_name=fms_script.log*' \
  -p 'keywords=["OutOfMemoryError","exception"]' \
  -p 'log_type=local' \
  -p 'node_name=<node_name>'
```

## 5. System Commands

```bash

python3 lakewatch_api_client.py -a collect_alarm_node_res_data \
  -p 'cluster_id=<cluster_id>' \
  -p 'strategy_name=process-basic-info' \
  -p 'env={"process_name":"fmsd"}' \
  -p 'node_name=<node_name>'
```
