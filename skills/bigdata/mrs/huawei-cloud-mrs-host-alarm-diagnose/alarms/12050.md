# Network Write Throughput Rate Exceeds Threshold (12050) Log Information

## I. Alarm Type

| Item | Content |
|------|---------|
| Alarm Name | Network Write Throughput Rate Exceeds Threshold |
| Alarm ID | 12050 |
| Alarm Type | Communication alarm |

---

## II. Log Directory

### 2.1 Log Priority

> When analyzing network write throughput rate anomalies, it is recommended to view logs in the following priority order:
>
> | Priority | Log Type | Description |
> |----------|----------|-------------|
> | 1 | System log | System-level network log information |
> | 2 | Kernel log | Kernel network records |

### 2.2 Log Path

| Log File | Path | Purpose | Priority |
|----------|------|---------|----------|
| System log | `/var/log/messages` | System-level network log information | 1 |
| Kernel log | `/var/log/kern.log` or `dmesg` | Kernel network records | 2 |

---

## III. Log Time Format

### 3.1 System Log Format

```
Dec 20 10:30:15 hostname kernel: [message]
```

| Field | Description | Example |
|-------|-------------|---------|
| Date/Time | Month Day Hour:Minute:Second | `Dec 20 10:30:15` |
| Hostname | Host name | `hostname` |
| Module | Kernel module | `kernel` |
| Message | Log body | `message` |

## IV. Abnormal Error Keywords

### 4.1 Network Throughput Keywords

| Keyword | Meaning | Severity |
|---------|---------|----------|
| `txkB/s` | Kilobytes transmitted per second | P3 |
| `txpck/s` | Packets transmitted per second | P3 |
| `txkB/s` exceeds 80% of NIC bandwidth | Transmit throughput rate reaches threshold | P0 |
| `bandwidth exceeded` | Bandwidth exceeded | P1 |
| `link speed` | NIC link speed | P3 |
| `Speed` | NIC negotiated speed | P3 |

### 4.2 NIC Status Keywords

| Keyword | Meaning | Severity |
|---------|---------|----------|
| `Link detected: no` | NIC link detection failed | P0 |
| `Speed: 1000Mb/s` | NIC speed 1Gbps | P3 |
| `Speed: 10000Mb/s` | NIC speed 10Gbps | P3 |
| `Speed: unknown` | NIC speed unknown (common in VMs) | P2 |

## VII. Common Root Causes and Repair Solutions

| Root Cause | Characteristics | Repair Solution |
|------------|----------------|-----------------|
| Unreasonable alarm threshold configuration | Write throughput rate below default threshold 80%, no business impact | Log in to Manager to modify threshold: O&M > Alarm > Threshold Settings > Cluster Name > Host > Network Write Info > Write Throughput Rate |
| NIC speed insufficient for business requirements | NIC speed low (e.g., 1Gbps), high business throughput | Contact network administrator to upgrade NIC speed, replace with 10Gbps or higher speed NIC |
| Business peak period | High throughput during specific time periods, not persistent | Expand node capacity or schedule high-throughput business during off-peak hours |
| NIC speed negotiation abnormal | NIC actual speed below rated speed | Check NIC negotiated speed, manually set: `ethtool -s <nic_name> speed <speed> duplex full autoneg off` |
| Single process consuming large bandwidth | A process with many network connections or large data volume | Identify high network traffic process, optimize its network usage pattern |
| NIC multi-queue not enabled | Single queue handling all interrupts, throughput limited | Enable NIC multi-queue, bind interrupts to different CPU cores |
