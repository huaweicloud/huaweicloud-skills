# Host Load Too High (12192) Log Information

## 1. Alarm Type

| Item | Content |
|------|---------|
| Alarm Name | Host Load Too High |
| Alarm ID | 12192 |
| Alarm Type | System Resource Monitoring |

---

## 2. Log Directory

### 2.1 Log Path

| Log File | Path | Purpose |
|----------|------|---------|
| Load log | `/proc/loadavg` | System load information |
| Memory information | `/proc/meminfo` | Detailed memory information |

---

## 3. Log Time Format

### 3.1 System Log Format

```
Dec 20 10:30:15 hostname kernel: [message]
```

### 3.2 Load File Format

```
0.52 0.58 0.59 1/1234 56789
```

| Field | Description | Example |
|------|-------------|---------|
| 1-minute load | 1-minute average load | `0.52` |
| 5-minute load | 5-minute average load | `0.58` |
| 15-minute load | 15-minute average load | `0.59` |
| Running processes | Running/total process count | `1/1234` |
| Most recent PID | Most recently started process ID | `56789` |

---

## 4. Exception Error Keywords

### 4.1 Load Related Keywords

| Keyword | Meaning | Severity |
|---------|---------|----------|
| `load average` | System load | 🟢 P3 |
| `high load` | High load | 🔴 P0 |
| `out of memory` | Out of memory | 🔴 P0 |
| `OOM killer` | OOM killer terminates process | 🔴 P0 |
| `killed process` | Process killed | 🔴 P0 |

### 4.2 Resource Related Keywords

| Keyword | Meaning | Severity |
|---------|---------|----------|
| `CPU usage` | CPU usage rate | 🟢 P3 |
| `iowait` | I/O wait | 🟠 P1 |
| `disk busy` | Disk busy | 🟠 P1 |
| `network error` | Network error | 🟠 P1 |
