## VPC 安全知识

**VPC默认安全组**

VPC默认安全组（名称为default）为系统内置资源，不可删除。为提升安全性，将所有出方向、入方向的安全组规则停用或改为Deny的操作权限。

**安全组与网络ACL的区别**

- **安全组**：实例（弹性网卡）级别，有状态（允许出方向自动放行回包）
- **网络ACL**：子网级别，无状态（入出方向规则需分别配置）
- 两者互补，网络ACL作为子网边界的第二道防线

**高危端口清单**

以下端口不应向公网（0.0.0.0/0）开放入方向规则：

| 端口 | 协议 | 服务 | 风险 |
|:-----|:-----|:-----|:-----|
| 22 | TCP | SSH | 远程命令执行 |
| 3389 | TCP | RDP | 远程桌面入侵 |
| 3306 | TCP | MySQL | 数据库未授权访问 |
| 6379 | TCP | Redis | 数据库未授权访问 |
| 27017 | TCP | MongoDB | 数据库未授权访问 |
| 9200 | TCP | Elasticsearch | 搜索引擎未授权访问 |
| 11211 | TCP | Memcached | 缓存服务未授权访问 |
