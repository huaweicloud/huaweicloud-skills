## Config 核心概念

| 概念 | API关键词 | 说明 |
|:-----|:----------|:-----|
| 记录器 | tracker | 记录资源配置变更，是Config服务的基础 |
| 合规规则 | policy_assignment | 定义合规检查逻辑，支持预定义和自定义两种 |
| 修正配置 | remediation_configuration | 定义不合规时的自动修正动作 |
| 高级查询 | stored_query | 使用SQL语法查询资源 |
| 资源聚合器 | configuration_aggregator | 跨账号聚合资源配置 |
| 合规规则包 | conformance_pack | 批量合规规则模板 |
| 组织合规规则 | organization_policy_assignment | 组织级合规规则下发 |
