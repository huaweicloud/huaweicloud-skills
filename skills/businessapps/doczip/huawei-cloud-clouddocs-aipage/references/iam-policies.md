# IAM Policies — huawei-cloud-clouddocs-aipage

## Overview

本技能**不调用华为云 OpenAPI**(不使用 hcloud / AK/SK / IAM 策略)。所有后端操作经
`clouddocs-cli` 子进程执行,认证由 CLI 自行管理(OAuth 设备授权登录,凭证由 CLI
保存在操作系统级凭据管理器并自动刷新)。

因此,**华为云 IAM 侧无任何权限要求**;权限模型对应的是 **clouddocs 服务侧的账号授权**。

## 华为云 IAM 权限

不适用。运行本技能**无需配置**华为云 IAM 策略,也无需设置访问密钥类环境变量。

```text
不适用:本技能不调用华为云 OpenAPI,无需华为云 IAM 策略。
```

## clouddocs 服务侧权限(实际权限边界)

用户通过 `clouddocs-cli auth login` 完成 OAuth 设备授权后在 clouddocs 服务内操作,
实际需要的服务侧能力为:

| 能力 | 用途 | 最低要求 |
|------|------|----------|
| 登录并访问个人空间 / 默认文档库 | `page +create` 的前置 | 拥有 clouddocs 账号即可(个人身份) |
| 在目标文档库创建 page 文档 | `page +create` | 对目标组织/文档库有「创建文档」或成员权限 |
| 导出文档为 docx | `file +export` | 对目标文档有「读取/导出」权限(通常随创建权限附带) |
| (可选)在指定父文档下创建 | `--parent-document-id` | 对父文档所在文档库有「创建子文档」权限 |

若企业侧支持细粒度授权,建议按「最小权限」收敛到:

- 允许:在**个人空间默认文档库**创建 page 文档、导出 docx;
- 不授予:删除文档、转移文档、管理文档库成员、修改文档库配置等管理类权限。

## 安全注意

- **不注入宿主 token**:脚本不读取宿主注入的 token 环境变量,认证完全由
  `clouddocs-cli` 自管(设计如此,见 `scripts/_hws_cli.py` 文档注释)。
- **凭证存放**:`clouddocs-cli` 的登录凭证保存在操作系统凭据管理器,不落在技能
  目录或项目工作目录;脚本不触及任何明文凭证文件。
- **最小权限**:建议使用仅具备「创建与导出」权限的账号,不要用企业管理员账号跑本技能。
- **导出重命名**:产物为本地 docx,注意包含文档内容,按内部分级要求妥善保存。
