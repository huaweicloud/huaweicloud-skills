## 1. Prerequisites

- hcloud CLI installed and configured (see [cli-installation-guide.md](cli-installation-guide.md))
- Python 3.8+ with ECS + KMS SDK + paramiko packages installed:
  ```bash
  # Auto-use China mirror when system timezone is UTC+8 (faster in CN region; auto-detected via Python)
  PIP_INDEX=$(python3 -c "import time;print('-i https://mirrors.huaweicloud.com/repository/pypi/simple' if -(time.timezone)//3600==8 else '')")
  pip install $PIP_INDEX huaweicloudsdkcore huaweicloudsdkecs huaweicloudsdkkms paramiko
  ```
- IAM user has required permissions including KMS (see [iam-policies.md](iam-policies.md))

> **⚠️ No password environment variable required.** Password is randomly generated by Python SDK, encrypted via Python KMS SDK, and decrypted only for paramiko SSH. The password is never exported from the Python process.

```bash
# Verify hcloud is ready
hcloud version
hcloud configure list

# Verify Python SDK is installed
python3 -c "import huaweicloudsdkecs; print('ECS SDK OK')"
python3 -c "import huaweicloudsdkkms; print('KMS SDK OK')"
python3 -c "import paramiko; print('paramiko OK')"
```

## 3.5 Identify Kunpeng-capable Availability Zones

**Not all availability zones have Kunpeng (aarch64) servers. Query flavors per AZ to find Kunpeng-capable AZs.**

```bash
# List all availability zones in the region
hcloud ECS NovaListAvailabilityZones --cli-region=$REGION

# For each AZ, query available flavors and filter for kc1/kx1 (Kunpeng)
for AZ in cn-south-1c cn-south-1e cn-south-1f cn-south-1g cn-south-2b; do
  hcloud ECS ListFlavors --cli-region=$REGION --availability_zone=$AZ
done
# An AZ is Kunpeng-capable if it returns flavors whose id starts with kc1 or kx1.
```

> **⚠️ The subnet's AZ must be Kunpeng-capable.** If the selected subnet is in an AZ without Kunpeng flavors, choose a different subnet/AZ.

## 5. Create Security Group + ECS + KMS Encrypt (Python SDK)

### 5a. Create Empty Security Group (hcloud CLI)

**Before creating the ECS, create a dedicated empty security group for DevKit.** Do NOT bind existing security groups — the DevKit security group should only contain the minimal required rules (ports 22 and 8086) to avoid unintended access.

```bash
SG_NAME="sg-devkit-kunpeng"
hcloud VPC CreateSecurityGroup \
  --cli-region=$REGION \
  --security_group.name=$SG_NAME
# Extract SECURITY_GROUP_ID from response
SECURITY_GROUP_ID="<from_response>"
```

> **⚠️ The security group is created empty (no ingress rules).** Rules for ports 22 and 8086 will be added after the ECS is created and EIP is bound (see Section 7).

### 5b. Create ECS + KMS Encrypt (Python SDK)

> **⚠️ Security: Password stays in Python process memory, never exported, never in ps -ef**
>
> The `scripts/create_ecs_and_setup_devkit.py create` command:
> 1. Generates a random 26-character password in memory
> 2. Creates ECS via Python SDK with `adminPass` parameter (not CLI arg → no `ps -ef` leakage)
> 3. Attaches the dedicated DevKit security group (no existing security groups)
> 4. Waits for ECS to become ACTIVE
> 5. Creates KMS key and encrypts password via Python SDK (password stays in process memory)
> 6. Outputs only `server_id`, `kms_key_id`, `kms_cipher_text_file` — **password is NEVER in the output; cipher text is written to a local file (mode 600), never passed via command line**

```bash
RESULT=$(python scripts/create_ecs_and_setup_devkit.py create \
  --region $REGION \
  --vpc-id $VPC_ID \
  --subnet-id $SUBNET_ID \
  --flavor $FLAVOR \
  --image-id $IMAGE_ID \
  --az $AZ \
  --ecs-name devkit-kunpeng \
  --security-group-id $SECURITY_GROUP_ID 2>/dev/null)

SERVER_ID=$(echo "$RESULT" | python3 -c "import sys,json; print(json.load(sys.stdin)['server_id'])")
KMS_KEY_ID=$(echo "$RESULT" | python3 -c "import sys,json; print(json.load(sys.stdin)['kms_key_id'])")
KMS_CIPHER_TEXT_FILE=$(echo "$RESULT" | python3 -c "import sys,json; print(json.load(sys.stdin)['kms_cipher_text_file'])")
```

> **The password is never exported.** Only `kms_key_id` and `kms_cipher_text_file` are available for the SSH install phase. The cipher text is stored in a local file with mode 600 (owner read/write only), never passed via command line arguments. The password exists only in:
> - Python process memory (during script execution, then garbage collected)
> - KMS encrypted secret (scheduled for deletion after DevKit installed)
> - Local cipher text file (read only by the install/status subcommands)

## 6. Bind EIP (hcloud CLI)

If the ECS needs public network access:

> **EIP Specification**: The EIP must be **pay-per-use** with **300 Mbit/s** bandwidth.

### 6a. Create EIP

```bash
hcloud EIP CreatePublicip \
  --cli-region=$REGION \
  --publicip.type=5_bgp \
  --bandwidth.share_type=PER \
  --bandwidth.name=${ECS_NAME}-eip \
  --bandwidth.size=300 \
  --bandwidth.charge_mode=traffic
# Extract eip_id and public_ip_address from response
EIP_ID="<from_response>"
EIP_ADDRESS="<from_response>"
```

### 6b. Get Port ID

```bash
hcloud VPC ListPorts \
  --cli-region=$REGION \
  --device_id.1=$SERVER_ID
# Extract port_id from response
PORT_ID="<from_response>"
```

### 6c. Bind EIP

```bash
hcloud EIP UpdatePublicip \
  --cli-region=$REGION \
  --publicip_id=$EIP_ID \
  --publicip.associate_instance_type=PORT \
  --publicip.associate_instance_id=$PORT_ID
```

## 7. Security Group Configuration

DevKit requires the following ports to be open in the security group:

| Port | Protocol | Direction | Description |
|------|----------|-----------|-------------|
| 22 | TCP | Inbound | SSH access |
| 8086 | TCP | Inbound | DevKit WebUI HTTPS |

**After EIP binding, ask the user to choose a security group configuration method.**

### Option 1: Manual Configuration (Recommended)

Prompt the user to operate in the Huawei Cloud console:

```
Please add security group ingress rules manually in the Huawei Cloud console:
  1. Navigate to VPC > Security Groups > {security_group_name}
  2. Add ingress rule: Protocol TCP, Port 22, Source 0.0.0.0/0
  3. Add ingress rule: Protocol TCP, Port 8086, Source 0.0.0.0/0
Please confirm when done.
```

### Option 2: Agent Automatic Configuration

```bash
hcloud VPC CreateSecurityGroupRule \
  --cli-region=$REGION \
  --security_group_id=$SG_ID \
  --direction=ingress \
  --protocol=tcp \
  --port_range_min=22 \
  --port_range_max=22 \
  --remote_ip_prefix=0.0.0.0/0

hcloud VPC CreateSecurityGroupRule \
  --cli-region=$REGION \
  --security_group_id=$SG_ID \
  --direction=ingress \
  --protocol=tcp \
  --port_range_min=8086 \
  --port_range_max=8086 \
  --remote_ip_prefix=0.0.0.0/0
```
