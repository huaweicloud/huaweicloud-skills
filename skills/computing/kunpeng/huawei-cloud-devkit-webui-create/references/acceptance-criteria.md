## 2. ECS Creation Acceptance

### ✅ Correct

```bash
# ECS architecture is aarch64
hcloud ECS ShowServer --cli-region=$REGION --server_id=$SERVER_ID | grep "os_ext_arch" | grep "arm64"

# ECS status is ACTIVE
hcloud ECS ShowServer --cli-region=$REGION --server_id=$SERVER_ID | grep "status" | grep "ACTIVE"

# Flavor is Kunpeng (k-series)
hcloud ECS ShowServer --cli-region=$REGION --server_id=$SERVER_ID | grep "flavor" | grep "k"
```

### ❌ Incorrect

```bash
# x86 architecture ECS → DevKit cannot be installed
# Non-Kunpeng flavor (c6/c7) → DevKit-All package incompatible
# ECS created via hcloud --server.adminPass → password leaked in ps -ef
```

## 3. KMS Password Storage Acceptance

### ✅ Correct

- ECS password was generated by Python SDK (random 26-char)
- Password was encrypted via Python KMS SDK (inside `create_ecs_and_setup_devkit.py create`)
- Only `kms_key_id` and `kms_cipher_text` were exported (password never exported)
- KMS key ID was recorded
- KMS key is scheduled for deletion via Python SDK (inside `create_ecs_and_setup_devkit.py install`) after DevKit installed

### ❌ Incorrect

- Password passed via `hcloud --server.adminPass` (visible in `ps -ef`)
- Password stored in environment variable `DEVKIT_ECS_PASSWORD`
- Password printed in conversation or logs
- Password exported to shell variable or stdout
- KMS key not scheduled for deletion after use
- KMS operations done via hcloud CLI instead of Python SDK

---

## 4. paramiko SSH Acceptance

### ✅ Correct

- Password decrypted from KMS in Python process memory
- SSH connection established via `paramiko.SSHClient.connect(password=decrypted)`
- Install scripts uploaded via paramiko SFTP
- DevKit installed via `exec_command()` on SSH channel
- Password variable deleted after use (`del password`)
- KMS key scheduled for deletion after DevKit installed

### ❌ Incorrect

- Using `expect` + `$env(DEVKIT_ECS_PASSWORD)` for SSH
- Using `sshpass -p <password>` for SSH
- Using COC passwordless login (requires UniAgent, adds unnecessary dependency)
- Password passed as CLI argument to any SSH command

## 7. Security Criteria

### ✅ Correct Security Practices

1. hcloud authentication via interactive configuration or environment variables; never provide AK/SK in conversation
2. **Python SDK** for ECS creation + KMS — `adminPass` passed as API parameter, not CLI arg
3. **hcloud CLI** for all other cloud operations — EIP, VPC
4. **Python KMS SDK** for password storage — encrypted, IAM-controlled, scheduled for deletion, password never leaves Python process
5. **Python paramiko** for SSH connection — password from KMS decrypt, passed as function argument, never in `ps -ef`
6. **paramiko SFTP** for script upload — no CLI password
7. **paramiko exec_command** for DevKit installation — no CLI password
8. Password variable deleted after use (`del password`)
9. KMS key scheduled for deletion after DevKit installed
10. Firewall/security group only opens necessary ports (22, 8086)

### ❌ Incorrect Security Practices

1. Provide AK/SK directly in conversation
2. Use `hcloud --server.adminPass` (password visible in `ps -ef`)
3. Export password to shell variables or stdout (password must stay in Python process)
4. Use hcloud CLI for KMS operations (should use Python SDK to keep password in process memory)
5. Use `expect` + `$env(DEVKIT_ECS_PASSWORD)` for SSH
6. Use `sshpass -p <password>` for SSH
7. Use COC passwordless login (unnecessary dependency on UniAgent)
8. Hardcode SSH password in scripts
9. Print or log the ECS password
10. Keep KMS key indefinitely without scheduling deletion

### Password Lifecycle Security Standards

| Method | Security | Description |
|--------|----------|-------------|
| Python SDK (ECS + KMS) + hcloud CLI (EIP/VPC) + paramiko SSH | ✅ Secure | Password in Python process memory only; KMS encrypted; paramiko function arg; deleted after use |
| `hcloud --server.adminPass` | ❌ Prohibited | Password visible in `ps -ef` |
| `expect` + `$env(DEVKIT_ECS_PASSWORD)` | ❌ Prohibited | Environment variable readable |
| `sshpass -p <password>` | ❌ Prohibited | Password appears on command line |
| COC passwordless login | ❌ Prohibited | Requires UniAgent (chicken-and-egg); third-party skill dependency |

### Tool Separation Standards

| Operation | Required Tool | Reason |
|-----------|--------------|--------|
| ECS creation | Python SDK | adminPass not visible in ps -ef |
| KMS encrypt/decrypt/delete | Python SDK | Password stays in Python process memory, never exported |
| SSH connection | Python paramiko | Password as function argument, not visible in ps -ef |
| DevKit installation | Python paramiko | Script execution via SSH channel, no CLI password |
| EIP create/bind | hcloud CLI | Standard cloud operation |
| VPC/security group | hcloud CLI | Standard cloud operation |
