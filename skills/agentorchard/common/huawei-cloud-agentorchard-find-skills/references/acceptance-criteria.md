# 验收标准

## 核心功能

### AC-1: 关键词搜索

- [ ] 输入自然语言关键词，返回相关 skill 列表
- [ ] 结果按评分降序排列
- [ ] 每个结果包含：名称、描述

### AC-2: 浏览意图识别

- [ ] 无有效关键词时，自动输出热门 skill + 引导语
- [ ] 识别浏览意图（如"有什么skill"、"华为云AI Gallery有什么skill"）

### AC-3: 无结果引导

- [ ] 无结果时输出引导语
- [ ] 引导用户输入更具体的关键词或尝试中英文切换

## 数据准确性

### AC-4: 数据实时性

- [ ] 每次执行从华为云 AI Gallery API 获取最新数据
- [ ] 不依赖本地缓存或静态数据

## 安全合规

### AC-5: 只读操作

- [ ] 不创建、修改、删除任何云资源
- [ ] 不需要 IAM 认证（公开 API）
- [ ] 不要求用户输入 AK/SK 或任何凭证

### AC-6: 无硬编码凭证

- [ ] 脚本和文档中不包含任何 AK/SK、Token、密码
- [ ] 不包含任何 `HUAWEI_`、`HW_`、`HWC_` 开头的环境变量引用

## 文件规范

### AC-7: 尺寸约束

- [ ] 文件总数 <= 30
- [ ] SKILL.md <= 500 行
- [ ] 目录总大小 <= 40MB
