# Windows迁移工作流

## 概述

Windows服务器迁移到华为云ECS采用**块级迁移（MIGRATE_BLOCK）**模式，
通过WinRM协议远程管理源端，SMS Agent安装在源端执行数据同步。

**主流程顺序**：Agent 启动并上报源端信息（SMS 注册）→ 创建目标端 ECS 主机
→ 在 SMS 中配置目标端并创建迁移任务 → 全量/增量同步 → 割接验证。

## 2. 各阶段详细说明

### 阶段1: 环境检查
- 检查hcloud CLI是否安装并配置
- 检查AK/SK是否有效
- 检查Python依赖包
- 检查目标region可用

### 阶段2: WinRM连接
- 通过WinRM协议连接源端Windows服务器
- 端口: 5985(HTTP) 或 5986(HTTPS)
- 认证: Basic认证，Administrator账户
- 验证连接可用性

### 阶段3: 前置检查
- 检查Windows版本是否受支持
- 检查.NET Framework版本
- 检查VSS服务状态
- 检查磁盘空间
- 检查WinRM配置

### 阶段4: 安全检查
- 检查源端防火墙规则
- 检查安全组配置
- 检查密码复杂度
- 检查网络隔离

### 阶段5: 网络准备
- 创建或选择VPC
- 创建或选择子网
- 创建或选择安全组（含RDP/WinRM规则）
- 申请EIP（如需要）

### 阶段6: 安装启动 Agent 并上报源端信息
- 通过 WinRM 传输并安装 SMS Agent（2012+ → Python3 GUI Agent；2008/7 → Python2 CLI Agent）
- 配置 AK/SK、SMS 域名、企业项目
- 启动 Agent，Agent 自动采集并上报源端信息（OS/磁盘/内存/CPU/IP）到 SMS
- 等待 Agent 上线（源端注册成功）

### 阶段7: 创建目标端 ECS
- 目标 ECS 名称与源端名称一致
- 按源端规格推导目标 ECS 规格/flavor 与 Windows 镜像
- 设置管理员密码（与源端一致，满足复杂度要求）
- GPT 分区磁盘目标容量 +1GB
- 创建 ECS 并等待 ACTIVE
- 绑定 EIP（公网迁移）

### 阶段8: 刷新磁盘
- 通过WinRM收集源端磁盘信息
- 刷新SMS中的磁盘数据
- 确认磁盘数量和容量

### 阶段9: SMS 配置目标端并创建迁移任务
- 指定源端服务器与目标端 ECS（exist_server=true 主路径）
- 创建MIGRATE_BLOCK类型任务
- 设置自动启动
- 可选: 设置持续同步(syncing)

### 阶段10: 数据同步
- SMS Agent通过VSS快照读取源端数据
- 块级数据传输到目标ECS
- 支持增量同步（仅同步变化数据）
- 一致性校验：数据完整性自动校验
- 监控进度和速度
- 等待同步完成（syncing=false）

### 阶段11: 割接(Cutover)
- 停止源端业务（建议）
- 执行最后一次增量同步
- 修改目标ECS引导配置
- 重启目标ECS
- 等待ECS启动完成
- 验证系统可正常启动

> **Cutover 注意事项**:
> - Cutover 前建议创建目标 ECS 快照备份
> - Cutover 后源端保持运行，可回切流量
> - GPT 分区磁盘目标容量需比源端大 1GB
> - 源端磁盘调整后无法增量同步，需重启 Agent

### 阶段12: 验证ECS
- 验证ECS状态为ACTIVE
- 验证RDP可连接(3389端口)
- 验证系统盘可启动
- 验证数据盘挂载
- 验证网络连通性

### 阶段13: 生成报告
- 收集迁移统计信息
- 生成迁移报告
- 上传日志到OBS

### 阶段14: 清理资源
- 卸载源端SMS Agent
- 删除SMS源端注册
- 清理临时文件
- 关闭迁移专用安全组规则

## 3. Windows vs Linux 迁移差异

| 阶段 | Windows迁移 | Linux迁移 |
|------|-------------|-----------|
| 远程连接 | WinRM (5985/5986) | SSH (22) |
| Agent安装 | MSI/EXE自动安装 | tar.gz手动/自动安装 |
| 迁移类型 | MIGRATE_BLOCK (块级) | MIGRATE_FILE (文件级) |
| 数据读取 | VSS快照 | rsync/tar |
| 目标镜像 | Windows公共镜像 | Linux公共镜像 |
| 目标认证 | admin_pass (密码) | keypair (密钥对) |
| 远程验证 | RDP (3389) | SSH (22) |
| 服务管理 | Windows Service | systemd |
| 防火墙 | Windows Firewall | iptables/firewalld |
| 脚本语言 | PowerShell | Bash |

## 4. 迁移模式

### 4.1 全量迁移（默认）
```
源端数据 ──全量同步──> 目标ECS ──Cutover──> 业务切换
```
- 一次性同步所有数据
- 适合停机窗口充足的场景

### 4.2 持续同步+割接
```
源端数据 ──增量同步──> 目标ECS (多次)
                    └──Cutover──> 业务切换
```
- 先进行多次增量同步
- 最后一次Cutover时做最终同步
- 适合减少停机时间的场景

### 4.3 批量迁移
```
Excel文件 ──读取记录──> 多个迁移任务 ──并行执行──> 汇总报告
```
- 从Excel读取多台服务器信息
- 支持并行迁移（可配置worker数）
- 生成汇总报告

## 5. 关键配置项

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| source_port | 5985 | WinRM端口 |
| os_type | WINDOWS | 操作系统类型 |
| migration_type | MIGRATE_BLOCK | 迁移类型（Windows 仅支持块级） |
| migration_timeout | 7200s | 迁移超时 |
| cutover_timeout | 1800s | 割接超时 |
| syncing | false | 持续同步模式 |
| use_public_ip | true | 使用公网迁移 |
| cleanup_on_failure | false | 失败时清理资源 |
| max_workers | 1 | 并行worker数 |
| speed_limit | 0 | 限速(Mbps, 0=不限) |
| enterprise_project | default | 企业项目名称 |
| proxy_server | (空) | 代理服务器地址（可选） |

## 6. SMS 迁移参数详解

### 6.1 迁移类型

| 类型 | 说明 | 适用场景 |
|------|------|----------|
| MIGRATE_BLOCK | 块级迁移 | **Windows 唯一支持**，通过 VSS 快照复制磁盘块 |
| MIGRATE_FILE | 文件级迁移 | Linux 专用，Windows 不支持 |

### 6.2 网络模式

| 模式 | 说明 | 适用场景 |
|------|------|----------|
| 公网迁移 | 源端通过公网连接 SMS | 源端有公网 IP |
| 私网迁移 | 源端通过 VPC 内网连接 SMS | 源端在华为云 VPC 内 |
| 代理迁移 | 源端通过代理服务器连接 SMS | 源端无法直连华为云 |

### 6.3 同步模式

| 模式 | 说明 | 适用场景 |
|------|------|----------|
| 全量同步 | 一次性复制所有数据 | 停机窗口充足 |
| 持续同步 | 多次增量同步 + 最终 Cutover | 减少停机时间 |
| 迁移演练 | 仅同步不启动目标 | 验证迁移可行性 |

## 7. 时间估算

| 源端数据量 | 预计迁移时间 | 建议带宽 |
|------------|-------------|----------|
| 50GB | 30-60分钟 | 100Mbps+ |
| 100GB | 1-2小时 | 100Mbps+ |
| 500GB | 5-10小时 | 500Mbps+ |
| 1TB | 10-20小时 | 1Gbps+ |

**注意**: 实际时间取决于网络带宽、磁盘I/O、数据变化率等因素。
建议先进行测试迁移以评估实际性能。
