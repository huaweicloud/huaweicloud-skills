# 代金券规则知识库（本地离线）

> 本文件沉淀代金券的规则与适用服务，供分析层推荐使用。数据源接入后可与真实接口交叉校验。

## 代金券类型

| 类型 | 说明 |
|------|------|
| 满减券 | 达到门槛金额可用 |
| 折扣券 | 按比例抵扣 |
| 定向券 | 限定特定云服务/规格 |

## 抵扣规则（通用）

- 代金券不可提现、不可转让、过期作废。
- 抵扣金额不超过订单应付金额，不足部分现金补足（组合付款）。


## 适用服务

代金券通常可用于以下主流云服务（具体以券面适用范围为准）：

| 服务 | 服务名称 | 抵扣规则 |
|------|----------|----------|
| ECS | 弹性云服务器 | 满减券/折扣券一般适用；教育/活动券通常可用 |
| OBS | 对象存储服务 | 满减券/折扣券一般适用；教育/活动券通常可用 |
| RDS | 云数据库 RDS | 满减券/折扣券一般适用；教育/活动券通常可用 |
| CCE | 云容器引擎 | 满减券/折扣券一般适用；教育/活动券通常可用 |
| GaussDB | 云数据库 GaussDB | 满减券/折扣券一般适用；教育/活动券通常可用 |

> 待接入真实数据后可与 BSS 交叉校验完善；特定活动券仅限活动指定服务。

## 组合付款推荐策略（分析层内置）

1. 优先「全额抵扣」的低规格方案。
2. 其次「券抵部分 + 现金补差额」组合。
