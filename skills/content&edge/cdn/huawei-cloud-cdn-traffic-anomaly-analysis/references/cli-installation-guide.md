# CLI Installation Guide

## Huawei Cloud CLI (hcloud / KooCLI)

### Installation

Download and install from the official site:
https://support.huaweicloud.com/hcloudcli/index.html

### Version Check

```bash
hcloud version
```

Ensure version >= 3.2.0.

### Configuration

```bash
hcloud configure
```

Follow the prompts to enter AK/SK and region.

### Verify Configuration

```bash
hcloud configure list
```

## Python

### Installation

Download from: https://www.python.org/downloads/

### Version Check

```bash
python --version
```

Ensure version >= 3.8.

## obsutil (Optional)

### Installation

Download from: https://support.huaweicloud.com/obs/index.html

### Version Check

```bash
obsutil version
```
